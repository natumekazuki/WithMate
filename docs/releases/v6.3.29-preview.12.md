# WithMate v6.3.29-preview.12

対象タグ: `v6.3.29-preview.12`

v6.3.29-preview.11以降に統合した通常履歴・軽量配信、共有HTTP MCP、次Turn予約、MonitorとAuxiliaryの操作改善を収録するソースプレビューです。Windows x64 installerはローカル生成のみとし、GitHub Release作成、installerのアップロード・インストールは含みません。

## 主な変更

- Audit専用画面と重複保存を廃止し、通常会話・artifactの操作結果と開始／終端の最小turnを正本に統一しました。表示用会話は最新60件と閲覧page、artifact詳細は必要時の取得に分け、実行中Mainは全履歴の複製を保持せず当該turnの追加分を保持します。保存本文を表示pageやpreviewで置き換えません。
- Memory／CharacterとGlossaryのmanaged MCP接続をMainの共有localhost HTTPへ集約しました。短命tokenとcaptured turnでowner・権限を固定し、取消・終端・binding失効時に無効化します。tokenをpromptや永続provider設定へ保存せず、第三者MCP設定は維持します。
- Main／Auxiliaryの通常Sendに次Turn予約を追加しました。受付順と捕捉した入力・実行設定を永続化し、実行中のSendは次Turnを予約します。予約項目のSteerと追加入力shortcutは現在のCodex Turnへの入力、承認・質問回答は既存の別経路です。受付結果不明の自動再送や、結果不明の実行の自動再実行は行いません。
- Auxiliaryの通常操作ownerを対象会話へ分離しました。MainとAuxiliaryのdraft・選択・送信対象・実行設定を取り違えず、Mainの次送信用Model／Depth等の選択を保存済み設定や実行中turnと分けます。
- Home／独立MonitorのRunning／Stoppedを、初期5:5の可変splitterにしました。ドラッグとキーボードで領域配分を変更でき、既存Session Windowのsplitterを再利用します。
- Codexのnative通知投影をWorkerへ分離し、liveは変更item単位で配送してMainの完全snapshotへ統合します。消費済みeventの不要な保持を解消し、未消費通知の保全、終端結果、非表示Rendererの再接続を維持します。受信FIFOの人工的な件数上限は設けません。
- 会話の全文検索・Messages navigatorを、storage ownerの短いcursor batchとDB非所有のCPU Workerへ分離しました。match総数と位置を保ちながら結果pageを有限にし、古いquery・取消・Window破棄の結果を後続へ適用しません。
- streaming Markdown・Glossary注釈の投影、再取得可能な画像／Details、Session metadata・Affect checkpoint、Home summary更新、Character使用順queryの処理を軽量化しました。再取得できる表示cacheと、保存済み本文・draft・実行ownerを区別して扱います。非選択Auxiliaryのstatus取得が一時失敗した場合も、同じrunの後続通知から再取得できます。

## 互換性と利用上の注意

- 既存V6の通常会話・artifact、最小turn、Timing、Affect、Memoryを保持します。schema更新でAudit専用interim、provider output、legacy event tableを物理削除します。過去詳細のバックフィルや全artifactの書換えは行わず、既存操作結果の欠損を成功やexitCode 0で補完しません。Audit専用の過去詳細を残す契約ではありません。
- 表示用の最新60件や有限検索pageは保存履歴の削除・要約ではありません。Memoryなど必要consumerの明示的なfull readを維持し、取消・失敗時の取得済みpartial本文と操作結果は通常履歴へ保存します。
- 予約の受付はProviderによる実行成功を意味しません。受付結果不明は同じrequest IDで照会し、実行結果不明では後続を保留します。明示的な後続解放も失敗を成功へ変更しません。実行中の通常Sendを、現在turnへの追加入力と混同しないでください。
- 共有HTTP MCPは当turnのnative設定だけに反映します。同一OS user上の攻撃的processからの秘匿や、port再利用時の別listenerへの誤送信防止を保証するものではありません。短命・turn限定credentialで権限と寿命を限定し、認可不能時に無認証へfallbackしません。
- preview.11までの注意点は[前回のリリースノート](v6.3.29-preview.11.md)を参照してください。本版の詳細は統合commitに固定した[Database Schema](https://github.com/natumekazuki/WithMate/blob/80a450c41d74dbb37943c558603a1d7348641dcb/docs/design/database-schema.md)、[V6 Database Foundation](https://github.com/natumekazuki/WithMate/blob/80a450c41d74dbb37943c558603a1d7348641dcb/docs/design/v6-database-foundation.md)、[Session Run Lifecycle](https://github.com/natumekazuki/WithMate/blob/80a450c41d74dbb37943c558603a1d7348641dcb/docs/design/session-run-lifecycle.md)、[Auxiliary Session](https://github.com/natumekazuki/WithMate/blob/80a450c41d74dbb37943c558603a1d7348641dcb/docs/design/auxiliary-session.md)、[Desktop UI](https://github.com/natumekazuki/WithMate/blob/80a450c41d74dbb37943c558603a1d7348641dcb/docs/design/desktop-ui.md)、[ADR 027](https://github.com/natumekazuki/WithMate/blob/80a450c41d74dbb37943c558603a1d7348641dcb/docs/adr/027-shared-localhost-http-mcp-turn-identity.md)に対応します。
