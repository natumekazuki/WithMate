# WithMate v6.3.25

v6.3.25は、v6.3.24以降に追加・変更された機能をまとめたリリースです。Sessionでの長い会話や複数Windowの操作性を改善し、Git履歴、Repository Glossary、キーボードショートカット、Memory runtimeの複数instance対応を追加しました。

## 主な追加機能

### Repository Glossary

- Git checkoutごとの`.withmate/glossary.yaml`を読み取り、Session右ペインで用語、別名、定義を表示できるようにしました。
- メッセージ内の登録語へ注釈を付け、選択した用語の定義へ移動できるようにしました。
- 用語集の検索、追加読み込み、ファイル更新の監視、初回監視失敗後の再試行に対応しました。
- managed Skill、CLI、MCP、Sessionに束縛された操作経路を追加しました。
- coding agentによる自発的な用語追加を設定でき、1 turnあたりの追加上限を指定できるようにしました。
- 初期用語集として、このrepositoryの`.withmate/glossary.yaml`を追加しました。

詳細は[Repository Glossary](../features/repository-glossary.md)を参照してください。運用手順は[Repository Glossary Runbook](../runbooks/repository-glossary.md)、責務境界は[ADR 022](../adr/022-repository-glossary-boundary.md)に記載しています。

### Git履歴とcommit時点のFile Preview

- File Explorerに`History`タブを追加し、repositoryのcommit履歴、commitに含まれるfile、commit差分を閲覧できるようにしました。
- commit時点のfileを中央previewまたは独立したFile Preview Windowで開けるようにしました。
- commit差分から同じcommit時点のfile previewへ移動できるようにしました。
- 再読み込みや選択変更の途中で、古い非同期結果が新しいpreviewへ混入しないようにしました。
- Git objectのpath identity、root scope、filter実行禁止、blob読込上限を既存のFile Explorer認可境界へ統合しました。

詳細は[Git履歴とcommit preview](../features/git-history-and-commit-preview.md)を参照してください。

### Session messageの縮小表示とnavigator

- 長いmessageを個別に縮小・展開できるようにしました。
- message一覧を短いpreviewで確認し、対象messageへ移動できるnavigatorを追加しました。
- 一括縮小・展開とキーボードショートカットに対応しました。
- 検索対象の縮小messageは一時的に展開し、検索終了後は元の状態へ戻るようにしました。
- Sessionを切り替えた場合は、縮小状態とnavigatorの選択が別Sessionへ漏れないようにしました。

詳細は[Messageの縮小表示とnavigator](../features/session-message-collapse-and-navigation.md)を参照してください。

### キーボードショートカット設定

- shortcut commandを中央registryで管理し、画面ごとの重複したkeydown判定を整理しました。
- Settingsに`Keyboard shortcuts`を追加し、変更を許可したcommandのキー割り当てを変更できるようにしました。
- messageの検索と縮小、file previewの検索、PreviewとSourceの切り替え、送信操作をshortcut registryへ統合しました。
- 入力欄、dialog、中央surfaceなどのscopeが競合する場合に、別surfaceのcommandを実行しないようにしました。
- 予約済み、競合、不正な組み合わせの登録を拒否し、既定値へ戻せるようにしました。

詳細は[キーボードショートカット](../features/keyboard-shortcuts.md)を参照してください。

### 前回のSession Windowを復元

- アプリ終了前に開いていたSession Windowの集合を保存するようにしました。
- Home右ペインの`Restore Sessions`から、現在開いていないSession Windowをまとめて復元できるようにしました。
- 読込中、既にopen、削除済み、読取不能なSessionを区別し、復元結果をHomeへ表示するようにしました。
- 複数Home Windowがある場合も、復元通知と操作結果をprimary Homeへ限定しました。

詳細は[Session Windowの復元](../features/session-window-restore.md)を参照してください。

### メッセージ画像のlightbox

- chat message内のraster imageをlightboxで拡大表示できるようにしました。
- Zoom Out、Zoom In、100%、Fit、Reload、Copy Imageを共通の画像viewportへ統合しました。
- Fit倍率を実際の画像描画へ反映し、拡大時のpan操作と暗色の操作UIを追加しました。
- file previewとmessage lightboxで画像操作の基礎実装を共有しました。

詳細は[メッセージ画像のlightbox](../features/message-image-lightbox.md)を参照してください。

### WindowsのCopy File

- WindowsでFile Explorerのfile row、File Preview header、認可済みMarkdown local-file linkから、file objectをclipboardへコピーできるようにしました。
- 日本語を含む非ASCII file名に対応しました。
- `Copy File`と画像内容をコピーする`Copy Image`を別操作として扱います。
- directory、認可root外のpath、不正なMarkdown linkでは操作を表示せず、失敗時にpath文字列へfallbackしないようにしました。

詳細は[WindowsのCopy File](../features/windows-file-object-copy.md)を参照してください。

### Prompt Templateの即時挿入

- Templateを選択すると、composerで保持していた選択範囲へpromptを即時挿入するようにしました。
- Template更新後も一覧のfocusと選択位置を維持するようにしました。
- Template、Skill、File Preview、Git履歴差分など、中央surfaceへ表示するworkspaceを相互排他にしました。
- TemplateとSkillのclose操作と英語labelを統一し、常設の補足文を削減しました。

詳細は[Prompt Template workspace](../features/prompt-template-workspace.md)を参照してください。

## 表示と操作の変更

### Markdown表示

- YAML front matterを本文から分離し、Previewではkey-valueの表として表示するようにしました。
- Markdown listの先頭行、隣接するlist item、改行を含むitemの余白を調整しました。
- fenced code blockの`Copy`を上部のsticky action rowへ移し、長いcodeでも操作へ到達しやすくしました。
- Mermaidではdiagram側の操作と重複しないよう、code block共通の`Copy`対象から除外しました。

詳細は[Markdown表示とcode block操作](../features/markdown-rendering-and-code-actions.md)を参照してください。

### Session interface

- messageの補助操作をmessage owner内のoverlayへ移し、本文layoutへ余分な幅や高さを確保しないようにしました。
- Session headerの操作を一つのgroup surfaceへまとめ、表示状態を切り替えても操作のまとまりが崩れないようにしました。
- artifactの`Details`でoperationを単一groupとして表示し、operationごとのsummaryと詳細を整理しました。
- Action Dockのprovider設定を通常幅では1行にまとめ、label、選択値、Send buttonの配置を調整しました。
- workspace再検証中のblocked状態とprompt送信エラーを分離し、送信失敗を別の状態で上書きしないようにしました。
- Template、Skill、File Preview、Git Diffの中央surfaceが重なって表示されないようにしました。

詳細は[Session interfaceの変更](../features/session-interface-refinements.md)を参照してください。

### HomeのSession一覧

- Recent Sessionsを全件読込からbounded queryへ変更しました。
- 一覧末尾から次のpageを追加読込できるようにしました。
- Session更新後の再取得でも、既に読み込んだpage数とscroll位置を維持するようにしました。
- Home用のsummary projectionを、open Sessionの詳細queryと検索条件から分離しました。

詳細は[Home Session一覧のpagination](../features/home-session-pagination.md)を参照してください。

## CharacterとAffect

### 別Sessionで生じたAffectの余韻

- 同じCharacterの別Sessionで保存されたAffect eventを、現在のSessionへread-timeの余韻として投影できるようにしました。
- session affectとrelationship affectを別々に減衰し、現在のSession内で生じたeventを優先します。
- source eventは書き換えず、投影時刻に応じて重みを計算します。
- 将来時刻、age zero、保持期間外、別Characterのeventを明示的に扱います。

詳細は[Cross-session Affect afterglow](../features/cross-session-affect-afterglow.md)を参照してください。

## 性能改善

### 長いSessionの操作応答

- message縮小previewの再計算を、変更されたmessageに限定しました。
- running turn開始時の保存を、全Session再保存から対象Sessionだけのincremental保存へ変更しました。
- HomeのSession一覧をsummary page単位で取得し、全SessionのJSONや本文を毎回展開しないようにしました。

詳細は[長いSessionの性能改善](../features/long-session-performance.md)を参照してください。

## 永続化とruntimeの信頼性

### running turn開始時の永続化

- user message、running状態、authoring snapshotを同じ開始transactionで保存するようにしました。
- 保存済みmessage全体を毎回書き直さず、追加messageと実行状態の差分だけを保存します。
- authoring開始時のCharacter snapshotを最新状態で固定し、validation失敗や保存失敗時に半端なsnapshotを残さないようにしました。
- v2、v3、v6の各storage adapterで同じ開始契約を使用します。

詳細は[running turn開始時の永続化](../features/running-turn-start-persistence.md)を参照してください。

### Memory runtimeの複数instance discovery

- 同じWindows userで複数のWithMate instanceが動作する場合に、Memory runtimeを共有registryへ個別登録するようにしました。
- operator CLIとunbound MCPは、active instanceが1件なら自動選択し、複数件なら曖昧エラーを返します。
- `instances`、`status --all`、`--instance`、`--generation`を追加しました。
- Sessionから起動されたproviderは、起動元instanceとruntime generationへ束縛され、別instanceへfallbackしません。
- registry mutationをprocess間lockで直列化し、publish、rollback、legacy pointer handoff、失敗cleanupの原子性を強化しました。
- registryにはcredential、secret、Memory本文、個人pathを保存せず、安全なdiagnostic metadataだけを公開します。

詳細は[Memory runtimeの複数instance discovery](../features/memory-runtime-discovery.md)を参照してください。設計判断は[ADR 023](../adr/023-multi-instance-runtime-discovery.md)に記載しています。

## 互換性と移行

- application dataの利用者向け手動migrationはありません。
- Memory runtime discoveryはv6.3.25のinstanceから共有registryを使用します。v6.3.24以前のinstanceは新registryへ候補を公開しません。
- Repository Glossaryは`.withmate/glossary.yaml`が存在するcheckoutで有効になります。未配置またはschema不正の場合はSession内に状態を表示し、既存のchat実行は継続できます。
- `Copy File`はWindows限定です。Windows以外では既存のpath操作を維持します。
