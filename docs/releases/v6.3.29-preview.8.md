# WithMate v6.3.29-preview.8

対象タグ: `v6.3.29-preview.8`

v6.3.29-preview.7に、Mermaidと画像の拡縮・表示移動、組み込みTerminalのコピー・終了確認、Windows配布buildの改善を追加するプレビューリリースです。

## 主な変更

- Mermaid図にZoom Out／Zoom In、現在倍率兼100%リセット、Fitを追加しました。中央・独立File Preview、Markdown、会話内で図ごとに操作でき、初期表示はFitです。大きな図は拡大してスクロール・keyboard操作で閲覧できます（[#763](https://github.com/natumekazuki/WithMate/issues/763)）。
- Mermaid、File Previewの画像／SVG、画像lightboxは`Ctrl`＋左ドラッグで表示位置を移動し、`Ctrl`＋ホイールで1ポイントずつ拡縮できます。ボタンは10ポイント刻み、手動倍率は10%〜800%です。通常の文字選択・スクロールを維持し、検索中の拡縮でも現在の一致位置を保持します。Previewの全選択・Copy／Quoteには倍率toolbarの文字を含めません。
- 組み込みTerminalの`Ctrl+C`は、端末の文字選択がある場合はコピーし、選択がない場合はシェルへ渡します（[#764](https://github.com/natumekazuki/WithMate/issues/764)）。
- Terminalが入力待ちと確認できた場合は、タブやWindowを閉じる際の端末理由の終了確認を省略します。実行中・起動中・判別不能・入力編集中は確認を維持し、複数行貼り付けの未確定入力も保護します。確認ダイアログを非同期にし、確認待ち中もMainのイベント処理・AI更新・他端末の処理が進むようにしました（[#765](https://github.com/natumekazuki/WithMate/issues/765)）。
- Windows配布buildでは、node-pty同梱prebuildとConPTY付随ファイルを検証して使用します。node-ptyだけを再ビルド対象から外し、他のnative依存の再ビルドとproduction依存の同梱を維持します。必要ファイルの欠損・空ファイル時にはpackagingを失敗させます。

## 互換性と利用上の注意

- 新しいDB migrationや既存の保存形式の変更はありません。preview.7までの変更・注意点は[前回のリリースノート](v6.3.29-preview.7.md)を参照してください。
- 図の倍率・表示位置は図ごとの表示状態で、他の図やWindowへ共有・永続化しません。Fitは小さい図を拡大せず、表示領域のサイズ変更に追従します。
- 終了確認を省略する入力待ち検出はWindows PowerShellが対象です。PSReadLineの編集bufferとconsoleの未処理入力が空であることを確認するまで、確認を省略しません。zshや検出できないPowerShell環境は判別不能として確認します。Job・processの調査は入力待ちへ入る時点の状態であり、別経路で後から開始された処理まで保証するものではありません。
- Windowsのpackagingはnode-ptyのローカルsource build結果を同梱対象から除外します。Windows以外は既定の再ビルドを維持します。
- リリース時の仕様は[Desktop UI](https://github.com/natumekazuki/WithMate/blob/1447348541a5bfb54731b4a1bd3506341951afd5/docs/design/desktop-ui.md)、[Electron Window Runtime](https://github.com/natumekazuki/WithMate/blob/1447348541a5bfb54731b4a1bd3506341951afd5/docs/design/electron-window-runtime.md)、[Distribution Packaging](https://github.com/natumekazuki/WithMate/blob/1447348541a5bfb54731b4a1bd3506341951afd5/docs/design/distribution-packaging.md)を参照してください。
