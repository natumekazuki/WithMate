# WithMate v7.0.1-preview.1

`v7.0.1-preview.0`から、同梱ランタイムと表示に使うライブラリを更新しました。

## 変更内容

- デスクトップアプリの実行基盤を Electron 44.11.5 に更新しました。同梱する Codex App Server を 0.171.0、GitHub Copilot SDK を 1.0.34、Claude Agent SDK を 0.3.330 に更新しました。
- PDFプレビューに使う PDF.js を 6.5.438、図の表示に使う Mermaid を 12.3.0、数式の表示に使う KaTeX を 0.18.10、コードの構文強調に使う Shiki を 4.6.0 に更新しました。
- 数式表示やアプリ内のHTTP処理などに使う依存ライブラリを、既知の脆弱性が修正されたバージョンに更新しました。
