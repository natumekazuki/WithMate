# WithMate v6.3.27

v6.3.27は、v6.3.26以降の会話・画面操作を改善するリリースです。1つのSession Windowで複数のAuxiliary会話を保持して切り替えられるようになり、Git履歴のbranch選択とSession MonitorからのWindow終了操作を追加しました。Action Dockのレイアウト、File Explorerの状態保持、Characterの対話校正も改善しています。

## 主な追加機能

### 複数のAuxiliary会話を保持・切り替え

- 1つのSession Window内でMainと複数のAuxiliary会話を保持し、ヘッダーから切り替えられるようにしました。
- 既存のAuxiliaryを閉じずに、`New Auxiliary`で別の会話を追加できます。
- 非表示のAuxiliaryでも会話、下書き、Character、実行状態を保持し、実行中の処理を継続します。
- 会話一覧にCharacter iconと会話previewを表示します。previewは確定済みassistant応答を基に更新し、AIによる要約生成は行いません。
- Auxiliaryごとに作成時のCharacter定義を保持し、親CharacterやCharacterカタログの後からの変更で差し替わらないようにしました。

Auxiliaryの会話内容はMainへ自動同期せず、Memoryやprovider contextも共有しません。詳細は[Auxiliary Session](../design/auxiliary-session.md)を参照してください。

### Git履歴のbranch選択

- File Explorerの`History`でローカルbranchを選び、そのbranchのcommit履歴を閲覧できるようにしました。
- 同じrepositoryを再読み込みした際に、repositoryとbranchの選択を保持します。
- 選択したbranchの削除・欠落、detached HEAD、空のrepositoryを画面上で説明するようにしました。
- branchと同名のtagが存在しても、選択したbranchの履歴を取得するよう修正しました。

選択対象はローカルbranchです。merge commitの詳細・差分はfirst parentを基準に表示します。詳細は[Git履歴とcommit preview](../features/git-history-and-commit-preview.md)を参照してください。

### Session Monitorからの操作

- AgentとCompanionの行のコンテキストメニューに、Session IDをコピーする操作と、対象Windowを閉じる操作を追加しました。
- 実行中のWindowを閉じる場合は、既存の確認処理を通します。
- 複数のAuxiliaryのいずれかが実行中の場合も、親Sessionを実行中としてMonitorに反映します。

## 表示と操作の改善

### Action Dockと会話レイアウト

- SessionとCompanionのAction Dockについて、上下配置や狭い画面での設定・入力操作を改善しました。
- 狭いレイアウトでは上下配置へ切り替え、設定領域と入力欄を確保します。
- 中央の会話領域が狭すぎる場合は一時的に折りたたみ、復元時に会話位置とスクロール状態を戻します。
- 左右ペインの開閉関係と、ドラッグ・キーボード・矢印操作によるサイズ変更を整理しました。
- 上下配置のDockを全幅にし、MainとAuxiliaryで表示が安定するようにしました。

詳細は[Desktop UI](../design/desktop-ui.md)を参照してください。

### 状態保持と表示の整理

- 送信前のWorkspace再検証やSession状態更新で、File Explorer左ペインの展開・選択・スクロール状態が失われる問題を修正しました。
- SessionFolder選択時の重複表示を解消しました。
- スクロールバーの色、幅、hover表示をtheme tokenへ統一し、forced-colors表示にも対応しました。

### 新規SessionへのCodex設定の継承

- 新規Sessionと新規Companionの作成時に、直近SessionのCodex `Reviewer`と`Speed`を継承するよう修正しました。
- 継承元の履歴がない場合は、既定値を使用します。

詳細は[Provider runtime設定の継承](../adr/007-provider-runtime-selection-inheritance.md)を参照してください。

## Characterの作成・対話校正

- `ImproveWithAgent`の校正手順を更新し、雑談に加えて作業中のCharacterらしさも確認するようにしました。
- 既存のCharacter定義、notes、feedbackを読み、回答済みの質問を繰り返さずに校正を進めるようにしました。
- 観察した挙動、仮説、定義の変更、別の入力による検証を分けて扱うようにしました。
- Characterの話し方と、コード・報告書などの成果物の形式を分離し、未実行の作業やシミュレーションを実行済みとして扱わないよう明確にしました。
- 新規Characterのtemplateとnotesに、平常時の存在感、本人らしさの手掛かり、参照情報の網羅性、変更履歴、作業場面での検証を記録する項目を追加しました。

詳細は[Character Authoring / Growth](../design/character-authoring-growth.md)と[Character authoringのKernel設計](../adr/011-character-authoring-kernel.md)を参照してください。

## 互換性と利用上の注意

- 既存Character定義の自動移行や一括書き換えは行いません。Character関連の変更は作成・校正ワークフローが対象です。
- 新規Auxiliaryの作成時に利用可能なCharacterがない場合や定義が不正な場合は、親Characterへ置き換えず作成失敗として扱います。
- 作成済みAuxiliaryのCharacter定義は、Characterカタログの変更やarchiveによって再生成されません。
- SessionとCompanion Windowの最小サイズは1100×720です。
