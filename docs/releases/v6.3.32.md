# WithMate v6.3.32

- Version: `6.3.32`
- Tag: `v6.3.32`

previewを挟まずに公開する正式版です。

## 変更内容

- 送信待ちメッセージに`Edit`を追加しました。本文をActionDockへ読み込み、同じ予約のまま更新できます。編集の取消では元の予約と通常の下書きを保持します。
- 予約の編集中は対象の会話だけ次の実行開始を保留します。実行中のTurnや別の会話は継続し、編集を確定すると本文から添付を再解決して保存します。予約の識別子・順序・実行設定は変更しません。
- Settingsの`Models`で、Providerごとに使用するModelを有効・無効へ切り替えられます。OpenCodeでは接続先サービス単位の切替、検索、開閉、一括切替、直前の一括操作のUndoに対応しました。変更は既存の`Save`で保存します。
- 無効なModelは選択候補から除外し、新しい送信の受付と実行開始前にも確認します。開いたままのModel候補には再有効化・無効化を反映し、検索・現在の選択・Depthと、開いた時点のSDK候補定義を保持します。
- Checkboxのチェック・中間状態・focus表示を共通化しました。
- Session GraphのTopic枠内の余白を整え、背景をドット模様から単色へ変更しました。
- Character promptの重複説明とIconのローカルパス注入を整理しました。Character本文、Affect・Timingの情報と、画面表示用のIconは維持します。

## 互換性・利用上の注意

- v6.3.31からDB schema versionとmigrationの変更はありません。Modelの有効設定は既存のアプリ設定へ保存し、SDKのModel cacheとは分離します。設定がないModelは有効として扱います。
- 選択中のModelを無効化しても、別のModelやDepthへ自動変更しません。そのModelで新しく実行する場合は、有効へ戻すか別の有効Modelを選択してください。受付済みの予約も開始時に無効なら実行されません。実行中のTurnは中断しません。
- OpenCodeのサービス無効化は個別Modelの設定より優先します。サービスを再有効化しても、個別に無効化したModelは無効のままです。
- 予約編集の検証・保存に失敗した場合は編集状態を保持します。内容を修正して再保存するか、編集を取り消すことで次の予約へ進めます。
