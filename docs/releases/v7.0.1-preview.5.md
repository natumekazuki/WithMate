# WithMate v7.0.1-preview.5

`v7.0.1-preview.4`から、4つのProviderで承認の選び方を揃え、会話枠をまたぐ操作と、各画面での読み込み中の表示を見直しました。

## 承認方針と子Sessionへの継承

- Main／Auxiliaryの `Approval` は、Codex・Claude・Copilot・OpenCode共通で `Auto Run / Auto Review / User / Safety Focused` の4択になりました。設定変更は次の送信に適用され、実行中のTurnと受付済みの予約は変わりません。Codexの `Sandbox` は別設定です。
- `Auto Run` は自動実行を選ぶ方針で、Providerの禁止・本人確認必須の規則を上書きしません。`Auto Review` はCodex／Claudeのネイティブ審査、Copilot／OpenCodeのWithMate仲介審査を使います。仲介審査を設定していない、利用できない、または本人判断が必要な場合は手動確認に戻り、選択値は変わりません。`User` は手動判断を選びます。`Safety Focused` は承認不要の操作やProviderで既に許可された操作を止めず、実際に承認を求められた操作は確認を出さず拒否します。OSによる隔離を追加する機能ではありません。
- Copilot／OpenCodeで従来の判断担当が未指定の場合は `Settings Default` と表示し、引き続きSettingsの `WithMate Auto Review` に従います。明示的な `User` は共通設定が有効でも手動になります。保存済みの旧制限（`untrusted`、Claudeの `Accept Edits / Preapproved Only / Plan`）は保持し、新規の選択肢には表示しません。仲介審査中の要求を手動で解決した場合や要求が取り消された場合は、その審査だけを停止します。
- MCP／配布CLIから通常の子Sessionを作る場合、同一Providerでは従来どおり、異なるProviderでも実行中の親Turnが使う共通の承認方針を引き継ぎます。宛先のネイティブ権限や管理者ルールは複製しません。制限付きSandboxのCodexから非Codexへ、選択済みCustom AgentのあるCopilotから異種へ、またはProvider固有の旧承認方針を異種へ引き継ぐ作成は拒否します。非CodexからCodexへの子作成では `Read Only` で開始します。旧Copilot／OpenCodeの判断担当が未指定なら、Codex／Claudeの子ではネイティブの `User`、Copilot／OpenCodeの子では未指定のままです。通常送信は引き続き宛先の保存設定を使います。
- WithMate内のOpenCodeではネイティブのサブエージェントを無効にしました。WithMateの通常子Sessionとは別の機能です。

## 会話枠とCoordination

- MainのGUIからの `Steer`、Coordination回答の返却、失敗したTurnの再実行で、それぞれ対象となる会話枠を維持します。保存済みの再実行では、元入力との一致を確認できない場合に元の入力者をそのまま表示しません。予約の編集は開始した枠に残り、別枠で通常送信しても編集中の予約を変更しません。停止操作は押した時点の実行・開始予約に限定し、後から始まったTurnは止めません。
- 他の枠に実行中のTurnや先行予約がある場合、後続予約には応答待ちを表示しません。実行終了後は、表示中の枠に確定した本文が届くまで表示済みの応答を保ちます。送信カードの本文は表示位置の近くで取得し、カードから別枠へジャンプした場合も対象位置を維持します。
- 会話内のCoordination通知は状態表示に必要な情報だけを取得し、起票一覧の更新は同じ対象への再取得をまとめます。Coordination画面では、回答の取得待ちと未回答、一覧の取得待ちと取得済みの0件を区別し、更新中も取得済みの内容と選択を保ちます。
- CodexのMCP質問フォームは不正な値を送信前に示し、質問を閉じずに訂正できます。質問への回答が次のTurnの予約を消費・変更することはありません。

## 読み込み中の表示

- Homeの起動準備・Preview一覧、SessionのModel・Skill・引用、Session Graph、Glossary、Coordinationなどで、読み込みの対象に合わせて待ち表示を見直しました。すでに取得した一覧や本文は更新中も使える状態を保ち、未取得を0件や検索結果なしとして表示しません。
- Markdown画像は取得が1秒以上かかる場合にだけ画像領域内で待ち状態を示します。代替テキストがあれば読み上げ名に含め、動きを減らす設定では回転を止めます。CodexのHTMLプレビューは初回取得中と手動 `Reload` の待ち表示を分け、失敗時は理由を表示して再試行できます。
