# WithMate v6.3.29-preview.20

対象タグ: `v6.3.29-preview.20`

preview.19へOpenCode provider、全Providerのモデル自動読込と検索選択、Affect更新の通常turn内MCPへの統一を追加したソースプレビューです（#879）。Windows x64の未署名installerもローカル生成しました。

## 主な変更

- OpenCodeを4つ目のProviderとして追加しました。固定版2.1.4のnative CLI／clientを同梱し、通常送信、会話継続、取消、承認・質問、Memory／Glossary／Session Graph MCPを既存Sessionへ接続します。Settingsで有効化とGo API keyの設定ができ、Goのquota情報も既存表示へ統合します。
- Codex、Claude、GitHub Copilot、OpenCodeのモデルとDepth候補をSDK／native一覧から読み込む方式へ統一しました。ProviderとWorkspace等のcontextごとにcacheし、取得中・失敗・正常emptyを区別します。同contextの既存候補は取得失敗後も保持します。
- Model選択を検索付きpopoverへ変更しました。モデル名・ID・配信元を検索でき、大量候補の仮想化、keyboard操作、IME、focus復帰に対応します。表示中の候補は背景更新で並べ替えず、選択時の定義をMain／Auxiliaryへ渡します。現在の選択、draft、実行中turn、受付済みqueueを背景更新で置き換えません。
- 手管理・同梱JSONのModel CatalogとImport／Exportを廃止しました。送信時にはModel／Depth等を捕捉し、catalog revisionや一覧への掲載を実行許可の条件にしません。
- Affectの専用post-turn生成、queue、retry、起動時回収を廃止し、通常turn内のAgentによるMCP更新へ統一しました。次turnのcontextと保存済みAffect／Memoryは維持します。

## 互換性と利用上の注意

- DBはV6を継続します。手管理catalogの3 tableとAffect専用settlement tableを削除します。未処理のAffect候補・retryは再開・再適用せず消去しますが、保存済みAffect event・episode・Memory、Session・会話・draft・最小turnは保持します。公開済みSessionの`catalog_revision`列値は保存互換性のため残し、実行条件には使用しません。
- OpenCodeのモデルIDは`<native provider>/<model>`、Depthはnative variantとして扱います。Go keyはChatGPT OAuthの代替ではありません。native DBはWithMateのuser dataとbuild channelごとに分離され、別のOpenCodeデスクトップ版のログインは自動共有しません。
- 保存済みModelが候補から消えても選択を保持します。ProviderがそのModel／Depthを拒否した場合は実行エラーとし、別ModelやProviderへ自動切替しません。初回候補取得に失敗し、同contextのcacheもない場合は一覧取得が必要です。
- Auxiliaryを直近Sessionから作成する経路では、モデル解決時のWorkspace引数が渡らない既知条件があり、別対応の対象です。
- Claudeの無表示終了・空応答（[#885](https://github.com/natumekazuki/WithMate/issues/885)）の修正、HTML Web機能拡張、および他の未統合branchは含みません。preview.19の既知残件は[前版ノート](v6.3.29-preview.19.md#互換性と利用上の注意)を参照してください。
- 本版の詳細は[Provider Adapter](https://github.com/natumekazuki/WithMate/blob/584d69d4e20c26054782ea6d76515627b425f2dc/docs/design/provider-adapter.md)、[Provider Model Discovery](https://github.com/natumekazuki/WithMate/blob/584d69d4e20c26054782ea6d76515627b425f2dc/docs/design/model-catalog.md)、[Affect更新の判断](https://github.com/natumekazuki/WithMate/blob/584d69d4e20c26054782ea6d76515627b425f2dc/docs/adr/028-in-turn-affect-mcp-only.md)を参照してください。
