# WithMate v6.5.0-preview.3

- Version: `6.5.0-preview.3`
- Tag: `v6.5.0-preview.3`
- 公開元: `feat/v6.5.0`

背景Agentのprompt構成を通常Sessionへ揃え、MemoryとCharacter Affectを登録だけでなく管理する役割へ広げたプレビューです。ソースをbranchとtagで公開します。

## 変更内容

### 通常Sessionと共通のprompt

背景のCharacter Memory・Target Memory・Character Affectに、通常と同じ設定に従ってCharacter定義とCharacter Affect Contextを供給します。用途別材料への二重投入をなくし、通常のprompt composerを利用します。

SessionFolderは元Mainのものを付与し、Auxiliaryでは親Mainのfolderを共有します。CharacterとAffectのownerは実際のMain／Auxiliaryのまま保持します。背景の独立thread、非対話実行、final本文を保存成功として扱わない契約は維持します。

### MemoryとAffectの管理

Character Memoryは既存episodeの参照・登録・訂正・忘却、Target Memoryは参照・登録・append＋supersedesによる訂正・忘却を行えます。書込先は用途ごとに捕捉したtarget内へ限定します。

背景Affectはinspect・appraiseに加え、誤ったeventをcorrectできます。管理権限は有効な背景Affect bindingから解決し、ユーザーの明示指示を偽装する入力は不要です。通常turnの訂正とresetは従来どおり明示指示を必要とし、背景にreset権限は付与しません。自然な感情変化の新規appraisalと、誤記録の訂正を区別します。

### ReadOnly参照

背景三用途から、通常認可範囲のMemory・Character context・診断、元Mainの共有Session Graph、許可checkoutのRepository Glossaryを参照できます。GraphやGlossaryの変更操作は許可しません。背景専用SessionやGraphは作りません。

異なるProviderを使う場合も実sourceのkind・incarnation・ownerIdentity・親・Characterとbinding／turn失効を検証します。同じIDのMainとAuxiliaryがあっても、Auxiliaryは自分の親Graphだけを参照します。MCPと配布CLIで同じ操作・認可を使います。

### 管理用プリセット

三用途のプリセットを管理役に合わせて更新しました。元記録と根拠を確認し、過去の出来事を新しい感情だけで誤りとして書き換えないこと、過去の指示を今回の操作依頼として実行しないことを示します。

## 互換性・利用上の注意

- 保存済みの編集本文は、空文字列を含め自動で置換しません。新しい標準本文へ切り替える場合はSettingsの該当用途で`Use Preset`を選んでください。
- 既存のMemory・Affect・Graphデータ形式、公開済みの単件／一括入力、通常turnの認可を維持します。DB migrationや既存データの再生成はありません。
- SessionFolder等へのnative file操作は選択したProviderのsandbox設定に従います。Memory添付の取込・復元には引き続き独立したfile認可を適用します。
- 公開対象はソース・tag・repository内ノートです。Windows x64向け未署名NSIS installerはローカル作成し、外部への配布物アップロードは行いません。
