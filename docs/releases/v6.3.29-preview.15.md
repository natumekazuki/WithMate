# WithMate v6.3.29-preview.15

対象タグ: `v6.3.29-preview.15`

preview.14以降の送信表示、チャット画像操作、Monitorの入力待ち分類、Memory MCPの利用案内を収録するソースプレビューです。Windows x64の未署名installerもローカル生成しました。

## 主な変更

- Main／Auxiliaryのプロンプト送信時に、受付応答を待たず送信本文と待機表示を会話へ反映します。入力欄の縮小と末尾追従の順序を整理し、受付前・予約中・実行中への切替で本文を重複表示しません。中断した先行予約がある場合も、後続の予約と受付待ち入力を送信順に表示します（#845）。
- チャットの最下部移動ボタンは、新着があっても「New activity」へ切り替えず、同じ矢印・寸法・外観を維持します。非表示から戻った際の閲覧位置引き継ぎもテストで確認します（#844）。
- キュー待機中のローカル画像に、通常の会話と共通の画像読込経路を適用しました。受付待ちの先行表示でも画像を表示します。
- チャット本文と拡大表示の画像から、右クリックで画像をコピーできます。ローカル画像では元ファイルのパスもコピーできます。通常のMarkdownプレビューとGit履歴内の画像でも同じ操作を利用できます。
- Auxiliary表示中もコピー通知が会話列の背後へ隠れないよう、通知の表示先を変更しました。
- Monitorの「Approval」を「Attention」へ変更し、承認だけでなく質問・MCP入力待ちも分類対象にしました。Main／Auxiliaryの待機を反映し、最後の要求が解決すると実行状態に応じた枠へ戻ります（#847）。
- Copilotの残率がNaN／Infinityなどの非有限値の場合、0%へ変換せず不明として表示します（#842）。
- Memory MCPへ、小さな好みや共有した出来事の記録、話題の開始・切替・再開での参照、検索語が不明な場合の少量一覧からの探索を案内しました。`memory.append`の`tags`は省略可能になり、空配列へ正規化します（#829）。
- Mermaidの解析失敗完了を待って直前の図の保持を検証するようにし、コピー通知CSSのテストは具体的な装飾値への依存を除きました（#824・#843）。

## 互換性と利用上の注意

- DB schema migrationの追加はありません。送信直後の先行表示はRenderer内の状態であり、受付順や永続化の正本は既存のTurn queueを維持します。
- Memoryの保存形式、明示tags入力、title／previewの必須入力、target権限と再送時の同一性確認は維持します。タグの自動生成や全会話の自動保存は追加しません。
- 外部URL・data・blob画像では、ローカルファイルのパスコピーを提供しません。パス解決とコピー時には既存のSession・参照元の認可を検査します。
- Monitorの表示領域・Window構成の検討（[#846](https://github.com/natumekazuki/WithMate/issues/846)）とvisualize記法の取り扱い検討（[#848](https://github.com/natumekazuki/WithMate/issues/848)）は本版に含みません。
- Codexのstdout解析失敗（[#797](https://github.com/natumekazuki/WithMate/issues/797)）と実行中の追加入力に関する報告（[#798](https://github.com/natumekazuki/WithMate/issues/798)）は別途追跡中です。今回の送信表示変更を、これらの実利用条件での解消確認とは扱いません。
- Windows installerは未署名です。詳細は本版の[Desktop UI](https://github.com/natumekazuki/WithMate/blob/469a17de482b2fb7135aa06d1339380fd5df2f96/docs/design/desktop-ui.md)、[Session Run Lifecycle](https://github.com/natumekazuki/WithMate/blob/469a17de482b2fb7135aa06d1339380fd5df2f96/docs/design/session-run-lifecycle.md)、[Memory / Affect MCP](https://github.com/natumekazuki/WithMate/blob/469a17de482b2fb7135aa06d1339380fd5df2f96/docs/runbooks/memory-affect-mcp.md)を参照してください。
