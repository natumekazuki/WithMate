# WithMate v6.3.29-preview.2

v6.3.29-preview.1以降のUI、会話操作、設定、Sessionの保存・復旧処理を更新するプレビューリリースです。

## 主な変更

- 起動表示をHomeへ統合し、Home、Session、Settingsのレイアウトと状態表示を整理しました。アプリが所有するUI文言を英語へ統一し、空状態、読み込み中、エラーの表示を見直しました。
- 保存済みmessageにブックマークを付け、右ペインのMessages navigatorを`All` / `Bookmark`で絞り込めるようにしました。MainとAuxiliaryの会話で利用できます。
- Settingsの`Prompt Context`で、Character定義、Character Affect Context、Conversation Timing、Tool Call Presenceの注入を個別に切り替えられるようにしました。既定ではすべて有効で、保存後の次のturnから反映します。
- SessionとAuxiliaryの作成・取消・保存・再取得が競合した際の状態復旧を改善しました。Audit更新失敗後の追加読み込みも再試行できます。
- Codex SDKを`0.156.0`へ更新し、renderer、IPC、共有契約の責務配置を整理しました。

## 互換性と利用上の注意

- Companion機能のUI、IPC、runtime、永続化経路を撤去しました。更新後の起動時に、管理対象のDBとバックアップからCompanion専用の記録・関連データを、専有blob、file、SessionFolderと専用Git namespaceのworktree・branch・base refを削除します。通常Session、共有Memory / Affect本文、共有file、他のworktree・branch・stashは保持します。Companion専用データを残す必要がある場合は、更新版を起動する前に別途バックアップしてください。
- v6.3.29-preview.1の通常Sessionと、Companionに属しないAuxiliaryは継続利用できます。MessageのブックマークとPrompt Contextの個別設定は、既存データに対する既定値を持ちます。
