# WithMate v6.3.29-preview.14

対象タグ: `v6.3.29-preview.14`

preview.13以降の質問UI、チャット追尾、承認通知、Provider残量表示と操作UIの改善を収録するソースプレビューです。Windows x64 installerもローカル生成します。

## 主な変更

- Codexの構造化質問を会話内へ配置し、選択肢・自由入力・Submit／Closeを整理しました。解決後の履歴には元の質問と選択肢を残し、回答フォームや回答状態ラベルは表示しません。質問前後の本文もFindの強調・移動対象に含めます（#799）。
- チャット追尾をユーザーの操作意図に合わせ、読み返し中の位置、再表示時のメッセージと行内オフセットを保持するようにしました（#822）。
- 処理中のボタンは寸法を保ったスピナー単独表示へ統一しました。Avatar操作は実行対象だけを処理中表示にし、通常の送信直後・実行記録の読込中は警告枠ではなくloadingとして表示します（#826・#825）。
- 承認待ち専用のWindows通知設定を追加しました。通知から対象のMain／Auxiliaryへ戻れます。通知にはSession名以外の要求内容を載せず、同じ会話の承認要求はFIFOで1件ずつ表示します。MonitorはApproval／Running／Stoppedに分けて表示します（#483）。
- Codex・Claudeの利用枠を定期取得し、MonitorとSessionの操作欄へ期間別の残率と詳細を表示します。Monitorの残量欄は折りたためます。取得失敗時は前回値と取得状態を区別します（#827）。
- Session HeaderとAction Dockの操作をアイコン中心に整理し、設定値の選択、keyboard操作、focus表示と操作間隔を調整しました（#827）。
- Add Directory By Pathの入力幅をAction Dockへ追従させ、共通のworkspace検証を使うようにしました。Windowsでは完全修飾パスを要求し、Auxiliaryの検証には親Session IDを渡します。
- 使用していないマニュアルチェックリスト本体と運用文書、現行の参照・更新義務を廃止しました。ADRと過去のリリースノートは履歴として保持します。
- 作業報告とリリースノートの規則を、実施内容・観測結果・利用上必要な事実を中心に整理しました。網羅的な未実施事項の列挙や自己評価を求めず、既知の失敗・制限と必須確認の扱いを維持します（#830）。

## 互換性と利用上の注意

- DB schema migrationの追加はありません。承認通知設定は既存の設定保存へ追加し、既定を有効にします。質問記録は既存message JSONの任意fieldへ種類・本文内位置を保存し、位置を持たない既存記録も表示します。
- 非同期質問の既定選択だけでは回答を送信しません。送信した回答本文は通常user messageとして保存し、フォーム入力値・既定値・再操作用のlive requestを質問記録へ保存しません。
- Copilotの会話・既存残量取得と表示は維持し、定期取得の対象には加えていません。非有限な残率が0%になる既知の問題は[#842](https://github.com/natumekazuki/WithMate/issues/842)で追跡します。
- Windows installerは未署名です。詳細仕様は本版に収録した[Desktop UI](https://github.com/natumekazuki/WithMate/blob/b032185da498b2708d9a2d4f4dd2cb96cc1ef930/docs/design/desktop-ui.md)と[Provider Usage Telemetry](https://github.com/natumekazuki/WithMate/blob/b032185da498b2708d9a2d4f4dd2cb96cc1ef930/docs/design/provider-usage-telemetry.md)を参照してください。

## 検証結果

- 全体test `npm.cmd test -- --test-concurrency=1` は3,329成功・1 skip・失敗0です。統合で追加された残量APIをtest fixtureへ補完し、取消・質問・header操作の期待を現行UI契約に合わせました。変更test全33件の価値reviewも完了しています。
- renderer／Electron／testの型検査、SQLite owner・dependency境界checkが成功しました。
- renderer／Electron／Memory CLI buildとWindows x64 NSIS installer生成が成功しました。installerは456,930,146 bytesです。Viteのlarge-chunk警告は残ります。
- 空のElectron出力からbuildした868 fileと配布ASARのbyte一致、対応sourceのないcompiled JSの不在、package／lock／ASARのversion一致、Memory／Glossary CLIとlauncherの収録を確認しました。
- 配布EXEのNode-modeで、koffi、Job ownership、supervisor、同梱Codex App Serverのinitialize接続とtransport終了を確認しました。認証を隔離し、推論requestを伴わない確認です。Codex／Copilot／Claudeの同梱実行物はproduction resolverで確認しました。
- native入力184 fileはpreview.13と同一です。前版のraw PTY検証で観測した、shell自然終了後のconsole列挙helperのAttachConsole診断は既知事項として引き継ぎます。
