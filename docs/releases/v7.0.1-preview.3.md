# WithMate v7.0.1-preview.3

`v7.0.1-preview.2`から、Sessionの会話切替、返信元・送信カードへの移動、WithMate Auto Reviewの設定表示を更新しました。

## 変更内容

- Mainの会話切替の先頭に `ALL` を追加しました。このMainの会話を相手で絞らず、送受信カードも元の順序でまとめて読めます。2番目の初期枠が引き続き既定です。相手別の枠は未読のものが先に並び、各グループでは会話の更新が新しいものが先に表示されます。一覧を開いたり `ALL` に切り替えたりしても、一括で既読にはなりません。
- Main／Auxiliaryの会話切替一覧をペイン内に収め、検索欄を残したまま候補をスクロールできるようにしました。実行中はアイコンの外周に弧を表示し、未読結果がある相手のタイトルやAuxiliaryのプレビューはMonitorと同じ青で表示します。
- 返信の引用を一行にまとめ、元の発言や送信カードをこのウィンドウ内で特定できる場合は、引用を選ぶとその位置へ移動します。送信カードの `@宛先` からも、相手別の枠にある同じカードへ移動できます。どちらの移動も送信先や下書きは変えません。新しい返信元として選べるのは保存済みの発言で、Session間の送信カードは選択対象から外れました。
- WithMate Auto Reviewの設定で、モデルやDepthを選んでいないときに表示される重複案内を削除しました。保存に必要な選択や、利用できない設定で手動承認に戻る動作は変わりません。
