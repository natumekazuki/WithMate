# WithMate v6.3.29-preview.19

対象タグ: `v6.3.29-preview.19`

preview.18以降のSession Graph、Main／AuxiliaryのDirectory共有、Sessionファイル掃除、Claude実行設定と各画面の操作・回復表示の改善を収録するソースプレビューです。Windows x64の未署名installerもローカル生成しました。

## 主な変更

- Session Graphを追加しました。要求・制約・判断・活動・観測・未解決事項をMainと配下Auxiliaryで共有し、agentが専用MCPから記録します。Session中央または独立Windowで話題、関係、詳細を辿り、段階的な区間展開、拡縮、パン、追加取得を利用できます。独立Graph WindowはHomeのPreviewsからも管理できます（#872）。
- Additional DirectoryをMainと全Auxiliaryで共有し、保存先をMainへ一本化しました。Main／Aux切替によるDirectory設定とFinder表示のズレを解消し、どの会話から追加・解除しても同じ親Session配下へ反映します（#884）。
- Settingsに`Clean Session Files`を追加しました。保存済みSessionの最終利用日をローカル日付・両端を含む期間で絞り、指定MiB以上のファイルの容量を計算し、確認後に完全削除できます。Sessionと会話履歴は残ります（#881）。
- ClaudeのApprovalに`Accept Edits`、`Preapproved Only`、`Plan`を追加し、`Provider Controlled`との組合せで`Auto Review`を利用できるようにしました。対応しない組合せは暗黙変換せず拒否します。Standard／Fastの要求をSDKへ明示し、利用不能や要求と異なる起動状態を通知します（#882）。
- MonitorでMain／Auxiliaryの最新ターン結果の未読を強調し、focusのある会話画面で結果を表示すると自動既読にします。本文のない結果は失敗表示または取得済みDetailsの閲覧を判定に使います（#878）。MonitorのSessionタイトルをコピーする操作も追加しました（#880）。
- 質問フォームの長い選択肢・自由回答と操作部が横へはみ出さないよう調整しました（#883）。
- Snapshot Diffの長い行と左右の行対応を調整しました。Previewの表示モード選択、Terminalのtab操作とfocus、Filesの狭幅操作・取得失敗からの回復を改善しました。
- Character Editor、Settings、Templates、Glossaryで取得・保存・失敗を操作単位に分離し、編集中の入力や取得済み内容を保持して再試行できるようにしました。Memory ReviewではGC結果と本文の表示領域を分け、Composerでは回復操作の位置を安定させました。
- Windowsのファイルコピー確認で同じClipboard data objectを再利用し、FileDrop情報の重複取得を減らしました。完了遅延に対する局所改善であり、報告された実環境の遅延解消は未確認です（#771）。

## 互換性と利用上の注意

- DBはV6を継続し、Session Graph用tableを追加します。既存SessionFolderのmmdを自動取込みせず、会話の自動要約も行いません。Graphは親Mainの削除で削除され、AuxiliaryのCloseでは保持されます。
- Additional DirectoryはMainの保存済み一覧を正本にします。既存Auxiliaryだけに保存されていたDirectory設定はMainへ移さず削除されます。必要なDirectoryは共有一覧へ追加してください。これは登録設定の変更であり、Directory内の実ファイルは削除しません。実行中ターンの権限は送信時の捕捉値を維持し、変更後の一覧は次ターンに適用します。
- `Clean Session Files`はごみ箱へ移さずファイルを完全削除します。履歴中の添付参照やPinは残るため、削除したファイルはそこから開けなくなります。実行中Main／Auxiliaryを持つSession、Workspaceと重なるfolder、孤立folder、リンク・junctionを除外し、削除直前にも対象を再確認します。SessionFolderルートは残します。
- 未読状態は起動中だけ保持し、アプリ再起動後に過去の結果から再構成しません。
- ClaudeのAuto Reviewはモデル・契約・managed policy、Fastはモデル・利用資格・追加課金条件に依存します。Approval／ReviewerはOSレベルのSandboxを保証しません。
- Claudeでエラー表示なくターンが終了し、空の応答が残る事象は[#885](https://github.com/natumekazuki/WithMate/issues/885)で調査中です。本版にその修正は含みません。
- 安定化された送信行をanchorにした履歴追加の既知条件は[#868](https://github.com/natumekazuki/WithMate/issues/868)、Homeのheader折返しと共通検索の対象表示は[#869](https://github.com/natumekazuki/WithMate/issues/869)・[#865](https://github.com/natumekazuki/WithMate/issues/865)で継続追跡します。既存のtest改善[#863](https://github.com/natumekazuki/WithMate/issues/863)・[#864](https://github.com/natumekazuki/WithMate/issues/864)・[#866](https://github.com/natumekazuki/WithMate/issues/866)・[#867](https://github.com/natumekazuki/WithMate/issues/867)と、承認済みの[#846変更test審査の後追い](https://github.com/natumekazuki/WithMate/issues/846#issuecomment-6294857166)も継続します。
- 未統合のHTML Web機能拡張とOpenCode providerは収録していません。HTMLは引き続き自己完結したinline CSS／JavaScriptと埋込み画像が対象です。
- 詳細は本版の[Session Graph](https://github.com/natumekazuki/WithMate/blob/921d60fe470a665e350306c017fb90e51e95029c/docs/design/session-graph.md)、[Session Local Files](https://github.com/natumekazuki/WithMate/blob/921d60fe470a665e350306c017fb90e51e95029c/docs/design/session-local-files.md)、[保存構造](https://github.com/natumekazuki/WithMate/blob/921d60fe470a665e350306c017fb90e51e95029c/docs/design/database-schema.md)、[Provider Adapter](https://github.com/natumekazuki/WithMate/blob/921d60fe470a665e350306c017fb90e51e95029c/docs/design/provider-adapter.md)を参照してください。
