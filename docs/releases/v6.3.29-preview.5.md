# WithMate v6.3.29-preview.5

対象タグ: `v6.3.29-preview.5`

v6.3.29-preview.4以降のSession Windowの更新境界、New Sessionの非同期操作、外部directory linkを改善するプレビューリリースです。

## 主な変更

- Session Windowで、会話本文、Files／Preview、Context／Glossary、Auditの状態・購読を各表示領域へ分離しました。streaming中の本文更新でWindow全体や変更のない確定履歴を再投影する範囲を減らし、非表示から再表示した会話は最新の内容へ追従します。Auxiliary一覧の投影と設定読込、選択中の本文に対する計測も必要な変更へ絞りました（[#737](https://github.com/natumekazuki/WithMate/issues/737)）。
- Main／Auxiliaryのsplitterはドラッグ中の幅を直接反映し、終了時に状態と任意記憶を確定します。遅い初期設定や送信準備の完了で、その後の手動開閉を巻き戻さないようにしました。Auxiliary draftの明示flushはdebounce待機を解除して保存完了を待ち、A→B→Aの切替や送信失敗でも後続入力を保護します。Template一覧の遅い初期取得も購読更新を上書きしません。
- New Sessionの連続openを単一の取得試行へまとめ、catalog取得中の入力を完了時に初期化しないようにしました。Cancel後や再表示後に古い取得結果が到着しても、現在のdialogへ適用しません（[#752](https://github.com/natumekazuki/WithMate/issues/752)）。
- Session開始要求の寿命をdialogの寿命から分離しました。開始後にCancelして新しいdialogを開いた場合、古い成功・失敗で新しい入力、focus、feedback、busy状態を書き換えません。閉じた要求で作成されたSessionはRecent Sessionsから開ける状態で保持し、現在のdialogを閉じた後に結果を表示します。古い要求の完了を理由にWindowを自動で開きません（[#753](https://github.com/natumekazuki/WithMate/issues/753)）。
- 会話やMarkdown previewで明示的にクリックした既存directory linkは、Sessionの登録root外もOSのfile managerへ渡せます。Mainでcanonical pathとdirectory種別を検査し、非同期解決後にも送信元の所有権を確認します。macOSではapp bundle等の起動を避けるため、通常folderも含めてFinderの選択表示を使います（[#748](https://github.com/natumekazuki/WithMate/issues/748)）。

## 互換性と利用上の注意

- 今回の差分に新しいDB migrationや保存形式の変更はありません。既存Session、確定message、必要なdraft保存、任意checkpointの境界を維持します。preview.3以前から更新する場合は、[preview.4の保存・移行に関する注意](v6.3.29-preview.4.md#互換性と利用上の注意)も確認してください。
- New SessionのCancelはdialogを閉じる操作です。既に受け付けた作成をbackendで取り消したり、作成済みSessionを削除したりしません。結果不明を成功として扱わず、自動再試行による二重作成も行いません。
- 外部directory linkを開いても、アプリ内のdirectory列挙、埋込み画像の読込、Additional Directory、Providerのアクセス許可は拡張しません。file linkのpreviewと汎用path openの制約も維持します。
- macOSでは対象folderの中を開くのではなく、親folder内で対象を選択表示します。OSへの引渡し後の実描画や、検査後の外部filesystem変更まで保証するものではありません。
- 現行の表示・状態所有は[Desktop UI](https://github.com/natumekazuki/WithMate/blob/93c8e8b44cf06325029c1fd513fb2ce24bf92058/docs/design/desktop-ui.md)、directory linkの判断は[ADR 025](https://github.com/natumekazuki/WithMate/blob/93c8e8b44cf06325029c1fd513fb2ce24bf92058/docs/adr/025-explicit-directory-link-open.md)を参照してください。

## 検証と未確認事項

- 4ブランチと統合時のNew Session競合解消をreviewし、統合を止める指摘はありません。変更testの抽出はdiagnosticなしで、全対象のtest-value reviewと競合解消後の増分審査を完了しています。
- 統合コードの `npm run typecheck` は成功しました。renderer、Electron、testの型検査とSQLite owner／依存境界checkを含みます。
- 統合コードの `npm run build` は成功しました。rendererの一部chunkには既存の500 kB超警告があります。
- 全体testは2,963件中2,962件成功、1件skip、失敗なしでした。
- 実HomeApp／SessionWindowAppとmock APIを使った1600×1000のブラウザー描画を確認しました。New Sessionのcatalog待ち中の入力保持、閉じた開始要求によるfocus・入力の保護と結果通知、Auxiliaryの送信・完了、非表示中のlive更新からの復帰、splitterドラッグ、File treeの表示を確認しています。
- 分離したElectronでのWindow lifecycle、実Provider、長い履歴・多数Auxiliary・並行実行の性能比較、日本語IME、macOS／LinuxのOS操作は今回未確認です。ブラウザーfixtureと自動testをこれらの実機検証や改善率の証明とは扱いません。#737、#748、#752、#753は残る受入確認を追跡するためopenを維持します。
- このリリースはversion、repository内リリースノート、Gitタグによるソースのpreviewです。installerの作成・配布は今回の検証に含みません。
