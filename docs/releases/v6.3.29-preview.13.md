# WithMate v6.3.29-preview.13

対象タグ: `v6.3.29-preview.13`

v6.3.29-preview.12以降のチャット・Action Dock・Terminal・File Previewの操作改善と、Codexの構造化質問への対応を収録するソースプレビューです。Windows x64 installerはローカル生成のみとし、GitHub Release作成、installerのアップロード・インストールは含みません。

## 主な変更

- TerminalのHTTP／HTTPSリンクをCtrl＋左クリックで既定ブラウザーへ開けるようにしました。通常クリックの選択操作を維持します（#815）。
- チャット上部のEarlier Messages／Later Messagesボタンを取り除き、既存の履歴スクロールを維持しました（#814）。
- Action DockのTerminal／Prompt切替とHideからの再展開で上部メニューを保持し、端末が0件になったらPromptへ戻るようにしました。再展開だけでは端末を自動追加しません（#817・#818）。
- File Previewの対象ファイルの絶対パスを専用領域に表示し、長いパスを折り返して確認できるようにしました。Git commitのpreviewでも対象rootに対応するパスを表示し、読取対象・認可は変えません（#816）。
- ストリーミング中のMarkdownを常に完全な構造で描画し、追記更新を集約して表の明滅を抑えました。終了・置換・検索時には最新本文を反映し、Mermaidは更新後の図が準備できるまで直前の図を保持します（#819）。
- Add Directoryのフォルダーピッカーを維持し、隣のAdd Directory By Pathから絶対パス入力で追加できるようにしました。Main／Auxiliaryの保存先を分離し、不正なパスや保存失敗では入力を保持します（#820）。
- Main／Auxiliaryを個別に末尾へ移動するキーボードショートカットをSettingsへ追加しました。既存の割当との衝突を避けるため初期値はNot Assignedで、送信対象や入力focusを変えず指定列だけ移動します（#821）。
- Codexの専用RPC質問と非同期の構造化質問を識別し、設定が有効で対象Windowが非focusの場合にWindows通知を出すようにしました。本文の推測で質問を判定せず、質問文・選択肢・入力値をOS通知へ出しません。回答・解決後は通知を撤去します（#823）。
- 非同期質問は選択肢・自由入力から現在Turnへ回答でき、質問の記録は解決後・終了後にread-onlyとなります。長いpaged履歴でも質問領域が潰れず、長文の質問や承認操作へ内部スクロールで到達できるようにしました（#823）。

## 互換性と利用上の注意

- 既存V6の会話・artifact・Memory・Affectの保持契約は維持します。本版の差分にDB schema migrationの追加はありません。
- 質問記録には質問文・選択肢とAnswer Submitted／No Form Responseを残し、formの入力値・既定値は記録へ保存しません。非同期質問の回答として受け付けた本文は通常user messageとして保存されます。RPC質問は元requestへの応答とします。
- 現在Turnが入力を受け付けない場合、非同期回答を次Turnへ自動振替しません。MCP elicitation・承認・通常会話・他providerをCodex質問通知の対象へ広げず、Monitorのstatusも変更しません。
- 本版の対象コードは統合commit `279c22fb4df8eb4eaa759f762cb24b73f82e9d98` です。詳細は同commitの[Desktop UI](https://github.com/natumekazuki/WithMate/blob/279c22fb4df8eb4eaa759f762cb24b73f82e9d98/docs/design/desktop-ui.md)を参照してください。以前からの互換性・注意点は[preview.12のリリースノート](v6.3.29-preview.12.md)を引き継ぎます。
