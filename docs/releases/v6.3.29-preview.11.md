# WithMate v6.3.29-preview.11

対象タグ: `v6.3.29-preview.11`

v6.3.29-preview.10以降に統合した内部負荷最適化と障害復旧のソースプレビューです。独立したSession Window、画面構成、通常の操作を維持し、Windowのタブ集約や未統合の改修は含めません。Windows installerはlocal生成のみで、配布やGitHub Release作成は含みません。

## 主な変更

- 実行中のAudit保存を、変更field／operation単位の増分commandと小さいACKへ変更しました。保存待ちの受付件数とpayload保持量に上限を設け、容量超過・保存失敗を明示的な失敗として扱います。承認・追加入力・取消・native終端通知を、詳細保存の完了待ちへ結合しません。
- Claude／Copilotの診断rawは受信時に秘匿化・サイズ制限を行い、JSON全体の512 Ki code units予算内で保持します。超過分は省略件数で明示し、最終出力まで無制限にrawを積み上げません。会話の最終本文、operationの順序、artifact、usageやthread情報を、このraw予算で切り捨てる変更ではありません。
- Window内のlive受信を一本化し、閉じたAudit／Contextや非表示の詳細projection・再取得可能cacheを休止・解放します。Changes／Historyは非表示時も全行描画へ戻さず、選択変更時の不要な全件再走査を抑えます。会話、draft、取消・承認の処理は表示cacheから独立して継続します。
- Character Affectの通常Context取得は、軽量stateと既存versionを同じread transactionで取得します。通常Contextへ不要なlayers／reason／eventIdsを展開・転送せず、小さいversion結果だけを有限cacheで再利用します。評価履歴、owner、reset／訂正、version形式は維持します。
- Codexの保存thread再開時に、利用しない過去turnの一括返送を省きます。同じthread IDとCodex側の会話履歴を維持し、長い履歴の不要な返送によるstdout frame上限超過を抑えます。protocol上限を広げたり、失敗時に別threadへ暗黙切替したりしません。
- Renderer終了・応答不能時のSession Window close／再openを整理しました。旧Windowの登録・購読を解放して同じSessionと既存runへ再接続し、表示障害や通知失敗をMain側の実行・取得済み応答の保存へ波及させません。
- 通常のStorage診断ログは、60秒区間ごとの有限集計へ変更しました。正常なqueued／started／completedごとの同期appendを抑え、失敗・その他のerror／fatalは即時記録します。正常終了時は残る集計をflushし、同一millisecondのログrotation衝突を回避します。

## 互換性と利用上の注意

- 保存済み会話・Memory／Character、認可、取消・承認・終端順序、通常draft保存／送信、Terminal継続を維持します。今回の改修に伴うユーザー操作のmigrationや、保存履歴の削除・要約は追加していません。
- 通常Window close／障害復旧では、flush失敗・timeout・Renderer終了などで保存できなかった入力中promptを失う場合があります。入力救済の保持保証や追加の破棄確認は設けません。保存済みdraft・送信済み会話・Main runと応答保存は維持し、app quitの保存・送信確定境界は通常closeとは別に保ちます。close成立を保存成功として扱いません。
- 診断rawと一部command outputの有限previewは、必要なAuditの黙った破棄とは別の制限です。受付容量超過・保存失敗・保存結果不明を成功へ変換せず、自動再実行による重複保存を行いません。
- Storage診断の異常終了時には、最後の未flush集計区間を失う可能性があります。記録済みの失敗／fatalを通常集計のために待たせる変更ではありません。
- preview.10までの注意点は[前回のリリースノート](v6.3.29-preview.10.md)を参照してください。今回の説明は統合commitに固定した[Audit Log](https://github.com/natumekazuki/WithMate/blob/d0d795e153b34087325dbe458b76b75a9a13e0c4/docs/design/audit-log.md)、[Provider Adapter](https://github.com/natumekazuki/WithMate/blob/d0d795e153b34087325dbe458b76b75a9a13e0c4/docs/design/provider-adapter.md)、[Session Run Lifecycle](https://github.com/natumekazuki/WithMate/blob/d0d795e153b34087325dbe458b76b75a9a13e0c4/docs/design/session-run-lifecycle.md)、[App Log Base](https://github.com/natumekazuki/WithMate/blob/d0d795e153b34087325dbe458b76b75a9a13e0c4/docs/design/app-log-base.md)に対応します。
