# WithMate v7.0.0-preview.4

- Version: `7.0.0-preview.4`
- Tag: `v7.0.0-preview.4`
- 公開元: `feat/v7.0.0`

運用設定を置換・解除するSession MCP操作の注釈を修正したpreviewです。`v7.0.0-preview.3`からの変更を収録します。

## 変更内容

- `session.set_selection_policy`、`session.set_worktree_root`、`session.set_worktree_repository`を、既存設定の置換・解除を含む書き込み操作として通知します。`tools/list`の`readOnlyHint: false`は維持し、`destructiveHint`を`true`へ変更しました（[#944](https://github.com/natumekazuki/WithMate/issues/944)）。
- 同時に追加した選定方針・quota・Worktree設定・配置先の4照会は、引き続き読み取り専用として識別できます。

## 互換性・利用上の注意

- 変更はMCPの操作注釈です。設定の保存・解除、bound CLIの入力・結果・効果、ユーザーの明示指示時にだけ恒久設定を更新する運用は変更しません。
- DB形式・migration、既存データ、Session・Turnの認可と配送契約に変更はありません。
- Windows x64向け未署名NSIS installerを用意します。インストールや起動中アプリの置換は自動で行いません。

## 検証結果

- 実装commit `9b6a01d6d6f41d42b04869be24fba0cae24bab58`の関連2 test file、9 testsが成功しました。SDK Clientで本番MCP serverの`tools/list`を読み、3更新操作と4照会の公開注釈を確認しています。
- production・script・test型検査、SQLite owner・依存境界check、Main・CLI buildが成功しました。変更testの独立レビューに指摘・統合ブロッカーはありません。
- `7.0.0-preview.4`のrenderer・PDF reader・Main・CLI buildとWindows NSIS生成が成功しました。未署名installerは683,205,270 bytes、blockmapは713,798 bytesです。既存のchunk size警告があります。
- 配布物のASAR内にある本番MCP serverへSDK Clientを接続し、`tools/list`で3更新操作の`readOnlyHint: false`・`destructiveHint: true`と、4照会の`readOnlyHint: true`を確認しました。
