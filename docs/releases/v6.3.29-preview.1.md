# WithMate v6.3.29-preview.1

v6.3.29-preview.1は、Auxiliaryの操作・状態表示・通知、File Previewのコピー結果通知、File ExplorerのGit履歴比較を改善するプレビューリリースです。

## 主な追加機能

### Git履歴のCompare

- File Explorerに`History`を追加し、認可済みGit rootのcommit履歴、commit時点のfile、commit差分をread-onlyで確認できるようにしました。
- `Compare`からlocal branch、remote-tracking branch、tag、`HEAD`、commit objectを対象に、Direct comparisonまたはBranch changesを実行できます。
- 変更ファイル一覧は既存のChangesと同じtree、filter、`Open All Changes`を利用し、rename、追加、削除では利用可能なbefore / afterをcommit時点のFile Previewで開けます。
- 比較時に解決したcommitを保持し、branch移動や再読み込みで表示中の差分が別の対象へ暗黙に置き換わらないようにしました。
- Historyはcheckout、reset、commit作成などを行わないread-only機能です。

詳細は[Git履歴とcommit preview](https://github.com/natumekazuki/WithMate/blob/04ac31a5c92b8c52ce104574e7ff2054df89fddb/docs/features/git-history-and-commit-preview.md)を参照してください。

## File Previewのコピー結果通知

- File Previewの`Copy File` / `Copy Image`の成功・失敗結果を、操作群と分離したheader内の共通通知overlayとして表示するようにしました。
- 成功は`success tone`と`role="status"` / `aria-live="polite"`、失敗は`error tone`と`role="alert"` / `aria-live="assertive"`で表示し、下部のpreview error表示とは分離しました。
- 通知は操作列のflex配置へ参加せず、既存のFind、Reload、Openなどの位置を移動・折り返しさせません。別窓File Previewでも暗色theme上で確認できるCSS契約を維持しています。

詳細は[File Previewの設計](https://github.com/natumekazuki/WithMate/blob/04ac31a5c92b8c52ce104574e7ff2054df89fddb/docs/design/desktop-ui.md)と[File Previewのmanual test](https://github.com/natumekazuki/WithMate/blob/04ac31a5c92b8c52ce104574e7ff2054df89fddb/docs/manual-test-checklist.md)を参照してください。

## Auxiliaryの改善

### 一覧と実行状態

- Auxiliary一覧を最終使用順で表示し、実行中の会話は一覧のCharacter icon内にprocessing indicatorを表示するようにしました。
- Auxiliaryの追加導線を切り替えUIのタイトル枠内にまとめ、Auxiliary領域を幅0まで閉じた場合は領域内のswitcherと追加buttonを隠し、splitterから再展開できるようにしました。
- Auxiliary領域の開閉、会話の選択、Main / Auxiliaryの送信対象を分離し、領域を閉じても会話、draft、実行状態を保持します。

### ActionDockのCancel領域

- compact / expandedの上段操作列で、`Main / Auxiliary`の直前に`Cancel`用の予約領域を常時維持し、非実行中は不可視にするようにしました。
- 通常幅では`86px`の固定幅、viewportが`760px`以下では操作列幅へ追従し、expandedの下段にはdisabledの`Send`を残すことで、Cancelの表示切替や送信対象の変更で主操作の位置が横にずれないようにしました。

### Session Monitor

- Homeと独立したSession Monitor Windowで、親Sessionに紐づくMainとAuxiliaryの状態を集約して表示します。
- 親Sessionの展開行からAuxiliaryのpreviewと状態を確認し、対象行を選択して同じSession Window内の会話を開けるようにしました。
- Auxiliaryの取得中・失敗時は、Auxiliaryが存在しない状態と混同しないstatus feedbackを表示します。

### 通知

- Windowsの通常Session WindowでAuxiliaryのturn完了・失敗を通知し、通知のclickから対象Auxiliaryを選択できるようにしました。
- Auxiliaryの削除時に、対象会話に紐づく完了通知も撤去します。

詳細は[Auxiliary Session](https://github.com/natumekazuki/WithMate/blob/04ac31a5c92b8c52ce104574e7ff2054df89fddb/docs/design/auxiliary-session.md)と[Windows Session turn通知のADR](https://github.com/natumekazuki/WithMate/blob/04ac31a5c92b8c52ce104574e7ff2054df89fddb/docs/adr/006-windows-session-turn-notifications.md)を参照してください。

## 互換性と利用上の注意

- 既存のSession、Auxiliary、provider設定を引き継ぎます。新しい設定項目の追加はありません。
- Git履歴とCompareはread-onlyで、checkout、reset、fetch、worktree作成などrepositoryを変更する操作は行いません。
- Auxiliaryの完了・失敗通知はWindowsの通常Session Windowが対象です。Companion、macOS、Linuxには同じ通知機能がありません。
