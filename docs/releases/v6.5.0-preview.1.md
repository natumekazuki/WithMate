# WithMate v6.5.0-preview.1

- Version: `6.5.0-preview.1`
- Tag: `v6.5.0-preview.1`
- 公開元: `feat/v6.5.0`

Memory・Character Affectの背景処理、Memory Review、Settings、Character表現の適用範囲を改善したプレビューです。前回の`v6.5.0-preview.0`からの変更をまとめます。ソースをbranchとtagで公開します。

## 変更内容

### 背景Sessionの継続と登録指示

同じ元会話・用途の背景処理は、独立したProvider threadを継続利用します。呼出しごとに現在の権限と接続情報を発行し、通常会話や別用途のthreadとは共有しません。同じ元会話・用途の処理は直前のcleanup完了後に進みます。

Character Memory・対象Memory・Affectの標準登録指示を整理しました。AIが既存記録と必要な保存済み履歴を確認し、登録・再検討する内容を選びます。Character MemoryはCharacter自身の口調で共有体験を記録し、観察事実と解釈を区別します。

失敗時は直後の自動再試行をせず、次に発火条件を満たす呼出しへ前回の失敗段階と選別した原因を渡します。失敗ログには操作ごとの成否と保存効果を追加し、tool操作の失敗をAgentの正常終了で成功扱いしないようにしました。

### Memoryの一括登録と添付

通常会話・背景処理とも、`memory.append`の`entries`と`character_memory.append_episode`の`episodes`で複数記録を一括登録できます。MCPとCLIの両方に対応し、項目ごとの保存済み・失敗・結果不明・未実行を返します。Memory登録件数とAffect候補数の固定上限を撤廃しました。

背景の対象Memory登録で添付を扱えるようにしました。背景三用途は、許可された既存Memoryの添付を必要に応じてSessionFolder内の`memory-exports/`へ復元できます。添付の取込元と復元先は呼出し時の許可範囲に限定し、既存ファイルを上書きしません。

### Memory ReviewとSettings

- Memory Reviewは対象名・アイコンを表示し、対象の絞り込みと一覧表示を揃えました。本文と対象を中心に記録を読み進められる構成に整理しています。
- Settingsのセクションと内側の設定グループを個別に開閉できます。選択欄を独立した行に配置し、Provider設定の開閉表示と説明を揃えました。

### 手元の記録へのCharacter表現

Session Graphや手元の作業メモなど、repositoryに含めず外部へ提出・公開しない自然文にもCharacter表現を使うよう、通常Sessionの指示を変更しました。repository内・外部向け成果物は、明示指定がない限り既存文体と目的を優先します。

口調を変えても、主体、事実・条件・状態、識別子、コマンド出力、正確な引用、権限や検証結果の扱いは変えません。既存記録の一括変換は行いません。

## 互換性・利用上の注意

- 保存済みの背景登録指示は自動で書き換えません。今回の標準指示へ切り替える場合は、Settingsで該当用途の`Use Preset`を選択してください。
- 公開済みの単件Memory登録入力・応答は維持します。一括登録の途中で失敗・結果不明になった場合、先行する保存済み項目は残り、後続項目は未実行になります。全件未保存として扱わないでください。
- 本文8,000文字、1 entryの添付10件、ファイルサイズ・quota等のAPI制約と、Provider・通信の制限は維持します。Character MemoryのepisodeとAffect候補には添付を追加していません。
- 添付の復元はローカルへのwriteです。Memoryのread権限だけでは許可せず、Codexの`read-only`および対応Providerの`plan`では復元できません。
- 背景thread、前回失敗、待機状態はアプリ再起動をまたいで復元しません。保存済みMemory・Affectは保持します。Provider切替では新しいthreadを使用します。
- 失敗ログは`userData/logs/background-failures.jsonl`へ追記します。本文・prompt・tool引数や応答本文はdumpせず、認証情報を除いた診断項目を記録します。
- このプレビューはソース公開です。別端末ではtagを取得し、`npm ci`の後に`npm run electron:start`でbuild・起動できます。Providerの認証は各端末で用意してください。
