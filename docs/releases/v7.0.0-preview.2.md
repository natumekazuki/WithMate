# WithMate v7.0.0-preview.2

- Version: `7.0.0-preview.2`
- Tag: `v7.0.0-preview.2`
- 公開元: `feat/v7.0.0`

親子Session連携でのMemory添付復元権限、Depth Defaultの継承、直接Steerの発言者表示を修正したpreviewです。`v7.0.0-preview.1`からの変更を収録します。

## 変更内容

- Memory添付の復元・書出には、実行中Turnで確定した実行権限を適用します。Sessionの保存値やGUIの次回実行設定を後から変えても、現在のTurnの権限は変わりません。保存値が制限設定でも書込可能なTurnでは復元でき、逆の場合は拒否します（[#940](https://github.com/natumekazuki/WithMate/issues/940)）。
- 子から親への通常報告でModel・Depthを省略した際、親の正当なDepth Default（空文字列）をそのまま受理し、次のTurnへ引き継ぎます。具体Depthの不正値や必須権限の欠落は引き続き拒否します（[#941](https://github.com/natumekazuki/WithMate/issues/941)）。
- 親からの直接Steerを、保存済みの入力ごとの送信元情報で表示します。親の名前・アバター・送信元リンクを使い、Turnを開始した別のAgentや通常のユーザー入力と区別します（[#942](https://github.com/natumekazuki/WithMate/issues/942)）。

## 互換性・利用上の注意

- DB形式、MCP／CLIの公開schema、通常送信・queue・Steerの配送方式は変更しません。既存のデータを保持し、新しいmigrationは追加しません。
- Memoryのパス認可と背景処理の権限境界を維持します。通常Turnの権限snapshotを確認できない場合、添付の書出は許可しません。Memoryのテキスト取得には影響しません。
- 送信元情報がない旧入力・GUIからの追加入力を、現在のTurn開始Agentへ推定で帰属させません。
- Windows x64向け未署名NSIS installerを用意します。インストールや既存アプリの置換は自動で行いません。
