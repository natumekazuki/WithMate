# WithMate v6.3.29-preview.4

対象タグ: `v6.3.29-preview.4`

v6.3.29-preview.3以降の保存境界、会話中の表示、Homeの取得・開始制御を更新するプレビューリリースです。

## 主な変更

- 現在の実行設定と再起動復元用の保存を分離しました。Model／Depth／Approval／Sandbox等はMainで検証した現在値をUIと実行に使い、任意checkpointの保存完了を操作条件にしません。Sendは押した時点の設定を固定し、後から選んだ設定や遅い保存結果と取り違えないようにしました。
- 実行中も次回向けのModel／Depthを選択できます。無効な設定や実行中に変更できない設定の拒否は、任意保存の失敗と区別し、有効な現在値と理由表示へ戻します。catalogのimport・reset後も現在のcatalogへ追従します。
- 小さい設定・タイトル・Bookmarkの更新で、変更していない会話本文やartifact詳細を全件読み書きする経路を減らしました。Auxiliaryのmetadata・message・artifact詳細を分離し、Audit更新も変更のない行を保持します。実行中の確定messageへのBookmark操作は、遅い完了結果で巻き戻さないようにしました。
- Header／Action Dock／pane、Auxiliaryの選択・幅、Window復元候補の任意記憶を現在の表示と分離しました。任意保存の失敗だけを理由にUIを戻したり、操作・Quitを待たせたりしません。
- 処理中表示をassistant応答枠へ統合し、Auxiliaryの送信文が応答待ちの間から表示されるようにしました。完了時の送信文重複や、遅い取得による巻き戻りを防ぎます。Action Dockの展開操作を見つけやすくし、Main／Auxiliary切替の実行中表示による位置ずれを抑えました。
- New Sessionは開いた時のCharacter一覧を閉じるまで保持し、表示・選択・開始候補を一致させます。Random開始はCharacter利用履歴とopen Session情報の取得成功を必要条件とし、Recent／Pinnedなど別領域の取得失敗を開始エラーへ混入させないようにしました。Homeの取得失敗と再試行は対象領域ごとに扱います。

## 互換性と利用上の注意

- Approval／Sandboxも再起動復元用checkpointは任意保存です。保存に失敗した最後の選択は稼働中には有効でも、アプリ再起動後は最後に保存された旧設定へ戻る場合があります。入力検証、owner照合、実行中の変更制約は維持します。
- Session identity、確定message、Turn／Audit、provider thread、Auxiliary draft、Character、Bookmark、明示的なSettings Save、catalog、credential・許可directoryの必要な保存を任意扱いへ変更するものではありません。必要な保存の失敗を成功として扱いません。
- Auxiliaryの既存payloadをmetadata・message・artifact詳細・独立draftへ分離する起動時移行があります。不正な行があれば全体をrollbackし、部分移行や黙ったデータ破棄は行いません。DBの全再作成は不要です。移行後の旧版へのダウングレードは今回検証していません。
- v6.3.29-preview.1以前から直接更新する場合は、[preview.2のCompanion専用データ削除に関する注意](v6.3.29-preview.2.md#互換性と利用上の注意)も確認してください。
- 保存と実行の契約は[Electron Session Store](https://github.com/natumekazuki/WithMate/blob/ccc907ea019450c62b9229a48890592fa0cec4cb/docs/design/electron-session-store.md)、Auxiliaryの保存形式は[Auxiliary Session](https://github.com/natumekazuki/WithMate/blob/ccc907ea019450c62b9229a48890592fa0cec4cb/docs/design/auxiliary-session.md#persistence)を参照してください。
