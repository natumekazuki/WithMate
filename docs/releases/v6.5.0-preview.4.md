# WithMate v6.5.0-preview.4

- Version: `6.5.0-preview.4`
- Tag: `v6.5.0-preview.4`
- 公開元: `feat/v6.5.0`

保存済みProject Memoryの参照先ID不一致を修正し、Codexの画像確認・待機・会話圧縮・子Agent活動を操作履歴へ対応したプレビューです。

## 変更内容

### Project Memoryの正規ID

通常Sessionと背景実行のProject authority、Memory管理対象を、既存storage Workerが解決する保存済みProject IDへ統一しました。同じProject keyのIDがcandidate IDと異なる場合にも、保存済みMemoryを参照できます。

新規Git Projectの初回保存と非Git workspaceの扱いは維持します。解決中にruntimeが切り替わった場合や元会話が解放された場合は、遅延結果から背景実行を開始しません。

### Codexの操作履歴

- `imageView`を画像確認の操作として扱い、Operationsへ対象ファイル名とpathを保存・復元します。[#931](https://github.com/natumekazuki/WithMate/issues/931)の対応です。画像本体の複製・別保存やチャット本文への自動挿入は行いません。
- `sleep`、`contextCompaction`、`subAgentActivity`を、待機・会話圧縮・子Agent活動としてOperationsへ記録します。実行中はitemの開始・完了をlive stepへ反映します。
- WithMate自身の追加入力受理診断を未対応警告から分離し、通常のinfo診断へ変更しました。本当に未対応のitemは引き続きbounded rawと警告を保持します。

## 互換性・利用上の注意

- DB migrationはなく、既存Project IDとMemoryを保持します。既存データの削除・再生成は不要です。
- 既存履歴と過去ログは書き換えません。新しいCodex操作表示は更新後に受信した操作へ適用します。
- 子Agent活動は操作履歴であり、Tasks UIの実行管理へは接続しません。
- 公開対象はソース・tag・repository内ノートです。Windows x64向け未署名NSIS installerはローカル作成し、外部への配布物アップロードは行いません。
