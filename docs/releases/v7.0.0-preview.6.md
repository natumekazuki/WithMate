# WithMate v7.0.0-preview.6

- Version: `7.0.0-preview.6`
- Tag: `v7.0.0-preview.6`
- 公開元: `feat/v7.0.0`

Coordinationの相談・回答を、受信会話で自然文として読めるようにしたpreviewです。`v7.0.0-preview.5`からの変更を収録します。

## 変更内容

- 相談・回答の本文と構造化された配送通知を分離し、受信した会話に内部JSONではなく送信者の本文を表示します（[#950](https://github.com/natumekazuki/WithMate/issues/950)）。
- Main／Auxiliaryの予約・保存済み会話と送信表示で同じ本文を扱います。通常のJSON入力は、Coordination通知として解釈しません。
- 共通execution読取の`get_execution`に、保存metadataで識別した配送の`coordination.id`と自然文の`coordination.text`を追加しました。MCP・bound CLIで共通の結果を返します。

## 互換性・利用上の注意

- 既存プレビューのJSON形式の受付・保存履歴も読み取れます。保存済みの原文を書き換えず、会話表示に自然文を投影します。
- Coordination ID・回答revision・送信者の来歴・状態・取り下げ理由は構造化通知に保持します。回答後の自動再開、入力保存時の取得済み確定、明示consume／resolve、通常enqueueの契約は維持します。
- DB schema・migrationに変更はありません。既存データとリリース済みpreviewの継続性を維持します。
- Windows x64向け未署名NSIS installerを用意します。インストールや起動中アプリの置換は自動で行いません。
