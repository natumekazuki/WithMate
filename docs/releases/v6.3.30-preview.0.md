# WithMate v6.3.30-preview.0

対象タグ: `v6.3.30-preview.0`

v6.3.29に、Codexの初回応答が実行中に表示されない問題の修正を追加したローカルプレビューです。Windows x64の未署名NSIS installerを生成しました。ソース・タグのpushとGitHub Releasesへのアップロードは行っていません。

## 主な修正

- 新規・既存Sessionで、Windowを開いてからの応答がリロードまたはターン終了まで表示されない問題を修正しました。
- 保存されたターンのIDとCodexのnativeターンIDを分け、受付済みの要求へ実行中の応答を正しく結び付けます。追加入力には引き続きnativeターンIDを使用します。
- Main／Auxiliaryで共通の表示処理を使い、応答待機から本文・続報・保存済み履歴へ同じ応答としてつなぎます。

## 互換性と利用上の注意

- v6.3.29からDB schemaと保存形式の変更はありません。本版で追加のmigrationや設定変更は不要です。
- Windows installerは未署名です。
- 実Codex通信による修正確認は、インストール後に新規・既存Sessionの初回送信で、リロードせず応答が表示されるか確認する段階です。
