# WithMate v6.3.29-preview.18

対象タグ: `v6.3.29-preview.18`

preview.17以降のHTML／PDFプレビュー、質問回答・承認・Session回復操作、Finder自動更新とHistory詳細の再取得を収録するソースプレビューです。Windows x64の未署名installerもローカル生成しました。

## 主な変更

- HTMLを中央・独立File Previewと会話本文内で表示できます。sandbox付きiframeで表示し、Reloadで描画環境を作り直します。File PreviewのFindはSourceへ切り替えて検索します（#849）。
- PDFの閲覧専用readerを中央・独立File PreviewとCodexの`visualize`による本文埋込みで共通化しました。ページ移動、表示モード、倍率・回転、全文検索、文字選択、サムネイル・目次・レイヤー・添付・文書情報、パスワード入力に対応します（#853）。
- 質問の自由回答を複数行入力にし、ファイル添付と貼付けに対応しました。添付処理中の回答選択を保護します（#862）。
- 承認要求を受信時の会話位置へ表示し、要求本文と許可・拒否を中心にしました。補足引数は情報アイコンから展開し、新しい質問が到着しても開閉状態とフォーカスを保ちます（#873）。
- Auxiliaryの作成待機に取消・再試行を追加し、作成中も親Sessionの監視を維持します。Sessionを閉じる際は、Mainだけでなく全Auxiliaryの実行状態を警告判断に含めます（#870、#877）。
- Sessionのエラー回復をAction Dockの再送・編集操作へ集約しました。送信・取消、pane再配置と本文表示の切替の遷移も調整しました（#871、#845）。
- Finderを自動更新し、更新をまたぐ閲覧位置・選択・フォーカスと後続取得を保持します（#875）。
- HomeのRecent Sessionsから通常種別のAgentと実行状態badgeを除き、実行状態の確認先をMonitorへ揃えました。Previews一覧はWindow数の多い親Sessionから並べます（#876、#874）。
- Historyのcommit詳細取得にRetryを追加しました。失敗理由は必要時にポップオーバーで確認でき、同じcommitの詳細再試行と進行中のDiff取得は互いの待機状態・失敗表示を消しません。

## 互換性と利用上の注意

- DB schemaと保存データの形式に変更はありません。
- HTMLは自己完結したinline CSS／JavaScriptと埋込み画像を対象とし、追加file accessとdocument navigationは許可しません。アプリ権限を隔離するもので、通信の完全遮断を保証する機能ではありません。Preview入力はUTF-8で50 MiBまでとし、上限超過・描画失敗時もSourceを利用できます。
- PDFの編集・保存・印刷・OCR・電子署名検証は提供しません。既存の注釈・フォーム値は閲覧のみで、XFAフォーム等の未対応内容は理由を表示します。パスワードは永続化しません。
- PDF readerの初期起動確認は15秒で打ち切り、応答がない場合はReloadを案内します。起動確認後のPDF解析・描画へ同じ期限を適用するものではありません。添付を自動実行・保存せず、文書外リンクはホストでの明示操作を経て開きます。
- 送信後の表示identityを保った行を先頭可視位置にすると、履歴追加の成功応答が反映されない既知条件は[#868](https://github.com/natumekazuki/WithMate/issues/868)で追跡中です。通常の履歴行へ位置を変えると取得でき、保存データは保持されます。Home header折返し時の共通操作群の右寄せは[#869](https://github.com/natumekazuki/WithMate/issues/869)、共通検索対象の視覚表示は[#865](https://github.com/natumekazuki/WithMate/issues/865)で扱います。
- 既存のtest改善[#863](https://github.com/natumekazuki/WithMate/issues/863)、[#864](https://github.com/natumekazuki/WithMate/issues/864)、[#866](https://github.com/natumekazuki/WithMate/issues/866)、[#867](https://github.com/natumekazuki/WithMate/issues/867)と、承認済みの[#846変更test審査の後追い](https://github.com/natumekazuki/WithMate/issues/846#issuecomment-6294857166)は継続します。
- 詳細は本版の[Desktop UI](https://github.com/natumekazuki/WithMate/blob/328aca15ae7a242e6f1d74555ac1400d01d93ef8/docs/design/desktop-ui.md)、[PDF readerの隔離境界](https://github.com/natumekazuki/WithMate/blob/328aca15ae7a242e6f1d74555ac1400d01d93ef8/docs/design/window-architecture.md#pdf-readerの隔離境界)、[Git History](https://github.com/natumekazuki/WithMate/blob/328aca15ae7a242e6f1d74555ac1400d01d93ef8/docs/features/git-history-and-commit-preview.md)を参照してください。
