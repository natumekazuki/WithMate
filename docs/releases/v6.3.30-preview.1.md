# WithMate v6.3.30-preview.1

対象タグ: `v6.3.30-preview.1`

v6.3.30-preview.0にSession Graphの表示改善を追加したローカルプレビューです。前版のCodex初回live応答表示の修正も含みます。ソース・タグのpushとGitHub Releasesへのアップロードは行っていません。

## 主な変更

- `All Topics`の初期表示をTopicごとのカードにしました。カードのダブルクリックまたは展開アイコン（▸）で、そのTopicの記録と有向関係を図上に展開します。
- 展開したTopicは見出しのダブルクリックまたは縮小アイコン（▾）で個別に閉じられます。他のTopicの開閉状態は維持します。
- 記録の種類・状態・担当と関係を図上で確認でき、記録を選ぶと全体を保ったまま一件の本文を開きます。Topic単独表示にも切り替えられます。
- 全体とTopic単独の往復、Graphの開閉で、展開状態・選択・倍率・閲覧位置を保持します。独立Windowを開く際にも閲覧状態を渡します。
- 開閉アイコンはkeyboardから操作でき、切替後は対応するbuttonへfocusを戻します。遅い読込応答が、利用者による縮小を取り消さないようにしています。

## 互換性と利用上の注意

- v6.3.30-preview.0からDB schema、保存形式、公開MCP／CLIの変更はありません。この表示改善による追加migration・Graph初期化はありません。Topicの展開状態は永続化しません。
- v6.3.29より前の旧プレビューから更新する場合、既存の保存契約切替処理により、未切替の環境では全Sessionの旧Session Graph（Topic・記録・関係・revision）を一度だけ初期化します。旧Graphの移行は行いません。この初期化は通常のSessionや会話、Memory、保存済みAffect、Character、参照先の実ファイルを削除せず、切替後に作成したGraphは以後の起動でも保持します。
- Windows installerは未署名です。
