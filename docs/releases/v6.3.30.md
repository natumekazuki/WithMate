# WithMate v6.3.30

対象タグ: `v6.3.30`

Codexの実行中応答表示の修正と、Session GraphのTopic別展開・縮小を含む正式版です。`v6.3.30-preview.1`の通常運用で問題がないとのユーザー確認を受け、同じアプリケーションコードを正式化しています。

## 主な変更

- Codexの応答がリロードまたはターン終了まで表示されない問題を修正しました。保存されたターンのIDとProviderのnativeターンIDを区別し、Main／Auxiliaryの受付済み要求へ実行中の本文・続報・保存済み履歴を正しく結び付けます。
- Session Graphの`All Topics`をTopicごとのカードで表示します。ダブルクリックまたは展開アイコン（▸）で記録と有向関係を展開し、見出しのダブルクリックまたは縮小アイコン（▾）でTopic単位に閉じられます。
- 記録の種類・状態・担当と関係を図上で確認でき、記録を選ぶと本文を開きます。Topic単独表示との往復やGraphの開閉で、展開状態・選択・倍率・閲覧位置を保持し、独立Windowにも閲覧状態を渡します。
- 開閉アイコンをkeyboardから操作でき、切替後は対応するbuttonへfocusを戻します。遅い読込応答によって利用者の縮小操作が取り消されることを防ぎます。

## 互換性と利用上の注意

- v6.3.29およびv6.3.30のpreviewからDB schema、保存形式、公開MCP／CLIの変更はありません。本版による追加migration・Graph初期化・設定変更は不要です。Topicの展開状態は永続化しません。
- v6.3.29より前の旧プレビューから更新する場合、既存の保存契約切替処理により、未切替の環境では全Sessionの旧Session Graph（Topic・記録・関係・revision）を一度だけ初期化します。旧Graphの移行は行いません。通常のSessionや会話、Memory、保存済みAffect、Character、参照先の実ファイルは削除せず、切替後に作成したGraphは以後の起動でも保持します。
- Windows x64 installerは未署名です。

## 検証結果

- preview.1の統合時に、Session Graph renderer／layout／読取状態／Window IPC・serviceと会話表示／Session runtimeの関連9 test files、113 testsが成功しています。renderer／Electron／testの型検査、SQLite owner境界と依存境界のチェックも成功しています。
- Codex表示修正は保存IDとnative IDを異なる値にしたfixtureで、Main／Auxiliary、新規／履歴ありの初回live表示、続報、完了時の重複・欠落防止を確認しています。
- Session Graphは隔離Electron・実IPCで、Topicの展開・縮小、keyboard／pointer操作、focus復帰、狭幅表示を確認しています。複数Topic・空・page・競合条件はcomponent／layout testで確認しています。
- preview.1のWindows配布物で、build出力とASAR内の内容一致、4 Provider・3 CLI launcherの同梱、配布ElectronのNode modeによるkoffi読込とPowerShell PTYの入出力・resize・終了を確認しています。
- 正式化の受入は、preview.1公開後の通常運用についてのユーザー報告に基づきます。これは個別の環境・操作を網羅した検証結果とは区別します。
