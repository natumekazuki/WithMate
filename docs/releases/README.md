# Release Notes

WithMateのrepository内リリースノートです。各リリースで利用者が認識できる追加機能、変更、互換性、検証結果をまとめます。

正式版・preview を問わず、リリース時は対象 commit へのリリースタグ付与とリリースノート作成を必須とします。タグが指す状態を互換性・継続性の維持境界とし、未リリースの途中状態を別の互換対象にしません。詳細は [AGENTS.md](../../AGENTS.md#compatibility-boundary-and-releases) を参照してください。

リリースノートには対象タグ・バージョン、変更内容、互換性・移行、実際の検証結果と未確認事項を記載し、下の一覧へ追加します。ノートの作成だけではリリース済みと扱いません。
