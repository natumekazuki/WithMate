# WithMate v6.3.29-preview.16

対象タグ: `v6.3.29-preview.16`

preview.15以降のMonitorレイアウト、生成ファイルのパス解釈、実行失敗表示、ターン完了状態の同期、visual checkのデータ選択を収録するソースプレビューです。Windows x64の未署名installerもローカル生成しました。

## 主な変更

- HomeのRecentとMonitor／Charactersを左右へ分け、表示領域を調整できるようにしました。各領域を閉じても共通headerから再表示できます。MonitorはMainの状態とAuxiliaryの状態集計をコンパクトに表示し、本文幅に応じて1列／2列へ切り替えます。分類ごとの高さ調整と折り畳み、独立Monitorの幅上限撤去にも対応しました（#846）。
- Monitorの一覧更新や幅切替で、同じ分類に残るSessionのDOM、操作focus、Auxiliary一覧のスクロール位置を保持します。表示の折り畳みはSessionの実行を停止しません。
- Codexの`visualize`記法とファイル引用からローカルファイルのパスを解釈し、Main／Auxiliaryのassistant本文とDetailsのプレビューで既存のファイルリンクとして扱います。元の応答本文は保持します（#848）。
- 完了状態の受付情報を読む処理から重複した更新通知を除き、再読込が次の再読込を呼び続ける循環を解消しました。完了済みターンの実行中表示を、正本の受付状態に合わせて解除します。
- 実行失敗の理由を生成本文と分離し、assistant側の共通エラー領域へ表示します。途中まで生成された本文を残し、ユーザー送信行との重複表示を除きました。編集・再送の導線と、実行結果が不確かな場合の表示は区別して維持します（#854）。
- `scripts/start-withmate-visual-check.ps1`に`-DataMode Reuse|Fresh|Copy`を追加しました。既定の`Reuse`は既存の検証データを再利用し、`Fresh`は未作成または空の保存先で開始します。`Copy`は検証データをインストール版のデータから作り直します。`-ValidateOnly`は条件確認とbuildだけを実行します（#855）。

## 互換性と利用上の注意

- DB schema migrationの追加はありません。実行失敗の情報はメッセージの任意項目として保存します。既存履歴は、失敗ターンとassistantメッセージの対応および末尾の理由文が一致する場合に限り、読込時に本文と理由を分離します。
- `visualize`対応はパス解釈とファイルリンクまでです。HTML、Excel、Word、PowerPoint、PDFの個別レンダリングは[#849](https://github.com/natumekazuki/WithMate/issues/849)〜[#853](https://github.com/natumekazuki/WithMate/issues/853)で扱います。
- visual checkは、従来の毎回コピーから既存検証データの再利用が既定になります。保存先がない場合は`Fresh`または`Copy`を明示してください。`Copy`は検証先を作り直すため、検証データを残したい場合は`Reuse`を選んでください。コピー元のインストール版データは変更しません。
- Codexのstdout解析失敗（[#797](https://github.com/natumekazuki/WithMate/issues/797)）と実行中の追加入力に関する報告（[#798](https://github.com/natumekazuki/WithMate/issues/798)）は別途追跡中です。
- Windows installerは未署名です。
- 詳細は本版の[Desktop UI](https://github.com/natumekazuki/WithMate/blob/532b3735f93815018375c0a3d569b8b8c6a9acdd/docs/design/desktop-ui.md)、[Message Rich Text](https://github.com/natumekazuki/WithMate/blob/532b3735f93815018375c0a3d569b8b8c6a9acdd/docs/design/message-rich-text.md)、[Session Run Lifecycle](https://github.com/natumekazuki/WithMate/blob/532b3735f93815018375c0a3d569b8b8c6a9acdd/docs/design/session-run-lifecycle.md)、[visual checkの起動方法](https://github.com/natumekazuki/WithMate/blob/532b3735f93815018375c0a3d569b8b8c6a9acdd/README.md#分離したvisual-check)を参照してください。
