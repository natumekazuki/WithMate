# WithMate v6.3.29-preview.21

対象タグ: `v6.3.29-preview.21`

preview.20へClaudeの終端処理・Approval操作、ファイル貼付の競合確認、チャット原文検索、HTML Web機能、ヘッダー操作の修正を追加したソースプレビューです。Windows x64の未署名installerもローカル生成しました。

## 主な変更

- Claudeの送信ごとにUUIDを付け、再開通知や別送信のresultを現在turnの完了として扱わないようにしました。入力streamを終端まで保持し、失敗・取消・終端前EOFでは受信済み本文や操作結果を残して失敗経路へ渡します。正常な空本文は引き続き受理します（#885）。
- ClaudeのApproval選択をReviewerの現在値で先に制限せず、Auto ReviewからUser専用のApprovalへ変更するときに確認を表示します。取消では元の設定を保ち、確定ではApprovalとReviewerを同時に更新します。Main／Auxiliaryとも古い確認による更新を拒否します（#882）。
- ファイル貼付時、同名・同内容なら既存ファイルを変更せず再利用して通知します。同名・別内容ならCancel、Save a Copy、Replace Fileを選択でき、置換直前にも内容を再確認します。通常入力欄と質問の自由回答で共通して利用できます（#886）。
- チャットのPreview検索で、表示本文に加えて元Markdownのリンク先なども検索します。同じ原文出現の二重計上を避け、原文だけの一致は選択中のSource Matchとして抜粋表示します。前後移動、Main／Auxiliary、保存履歴・未保存tail・pendingの検索を維持します（#887）。
- Filesの常設共有ラベルを削除し、追加dialog・一覧の適用範囲表示は残しました。Graph入口を展開中のヘッダー内に揃え、ヘッダーを閉じてもボタンが残る問題を修正しました（#884）。
- HTMLプレビューをmountごとの隔離されたWeb環境へ拡張しました。外部CSS／JavaScript、通信、worker、iframe、Web storage等をブラウザーの制約内で利用し、権限要求・子Window・外部アプリ起動はhost側で確認します。子Windowの終了や文書遷移で保留中の確認を取り消します。
- チャット本文と折りたたみ／Bookmarkの操作領域を分け、長いファイル名や狭い列でHTMLのReloadクリックが遮られる問題を修正しました。

## 互換性と利用上の注意

- DBはV6を継続し、本版で追加のschema migrationはありません。既存の会話・draft・設定を保持します。
- HTML内の情報や入力内容は外部通信で送信される可能性があります。Node.js、アプリpreload、WithMate IPCはHTMLへ公開しません。CORS、secure context、OS権限、Electronの対応範囲は緩めていません。
- HTMLの選択済み機器の許可は同一origin・同一mount内で維持します。Reload、Source切替、画面外破棄などでは新partitionとなり、以前の許可や内部状態を引き継ぎません。
- File System Access APIの選択済みhandleによる読書きは未対応です。通常の`input[type=file]`による明示選択読込みとは別の制限で、[#890](https://github.com/natumekazuki/WithMate/issues/890)で追跡します。
- ファイルのReplaceは同じpathを参照する過去の会話にも影響します。元の内容を残す場合はSave a Copyを選択してください。検索はリンク先ファイルの内容や埋込み文書の内容まで読み込みません。
- Session GraphのCharacterノードがUserと同じ汎用アイコンになる報告は[#889](https://github.com/natumekazuki/WithMate/issues/889)で別途対応します。本版にその修正は含みません。ほかの既知制限は[前版ノート](v6.3.29-preview.20.md#互換性と利用上の注意)を参照してください。
- 詳細は[HTML Preview Isolation](https://github.com/natumekazuki/WithMate/blob/5ce439b4fb81766e5a92caffa4a4fe8fb0edb8ee/docs/design/electron-window-runtime.md#html-preview-isolation)、[Provider Adapter](https://github.com/natumekazuki/WithMate/blob/5ce439b4fb81766e5a92caffa4a4fe8fb0edb8ee/docs/design/provider-adapter.md)、[Session Local Files](https://github.com/natumekazuki/WithMate/blob/5ce439b4fb81766e5a92caffa4a4fe8fb0edb8ee/docs/design/session-local-files.md)を参照してください。

- 各branchの変更test審査と、統合後のIPC fixture修正の独立審査を実施しました。統合全体の追加抽出はHTML testの空行対応を解決できず未完了です。ユーザー指定により、今回の公開では共通抽出ルール変更と停止中の追加抽出・審査を省略しました。

- 生成実行ファイルのNode modeでcanvas／koffi読込み、PowerShell PTYの入力・出力・resize・終了、4 Providerのバイナリ解決を確認しました。隔離データでOpenCode 2.1.4とCodex 0.159.0 app-serverの接続開始・終了、owned processの終了を確認しました。推論要求は行っていません。
