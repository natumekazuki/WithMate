# WithMate v6.3.28

v6.3.28は、会話内のMarkdown画像の表示とSession Windowのヘッダーメニューを修正するリリースです。

## 修正と改善

### Markdown画像の表示を安定化

- Main/Auxiliaryでプロンプトを入力した際に、表示済み画像が作り直され、読み込み表示へ戻る問題を修正しました。
- 同じ位置の画像は、リンク操作用コールバックの更新、画像部分を保った本文末尾への追記、軽量表示から完全表示への切り替えでも、画像DOMと読み込み状態を保持します。
- 即時の「Image loading…」表示を、読み込み待ちが1秒を超えた場合だけ表示する小さなスピナーへ変更しました。スピナーは画像領域に重ねて表示し、完了・失敗時に消えます。
- 動きを減らす設定ではスピナーの回転を停止します。
- 実際の画像source変更やFile PreviewのReloadでは再読み込みを行い、古い処理の完了や画像resourceの解放を扱う既存の契約を維持します。

関連: [Issue #714](https://github.com/natumekazuki/WithMate/issues/714)、[Message Rich Text](https://github.com/natumekazuki/WithMate/blob/61cf319113fe2d7ee0f73fc5980de7d684b78590/docs/design/message-rich-text.md)

### Session Windowのヘッダーメニュー

- ヘッダーの展開メニューが中央領域との境界で切り取られ、項目が隠れる問題を修正しました。

## 互換性

- 画像の読み込み開始条件、外部画像の通信方針は変更していません。
