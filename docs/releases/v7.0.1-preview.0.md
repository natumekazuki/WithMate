# WithMate v7.0.1-preview.0

Session間の送受信と会話履歴の表示を改善し、報告された問題の切り分けに必要な診断情報を追加したpreviewです。`v7.0.0`からの変更を収録します。

## 変更内容

- 送信元の応答内に宛先付き送信カードを配置し、同じ応答内で複数の宛先へ送信した場合も、宛先と受付順を確認しやすくしました（[#953](https://github.com/natumekazuki/WithMate/issues/953)）。本文内の位置は近似で、過去の送信で位置を復元できない場合は、その旨を表示します。
- 受信したメッセージの送信元CharacterとSessionの色を表示します（[#958](https://github.com/natumekazuki/WithMate/issues/958)）。
- 開始済みのQueue項目に古い待機操作が残る表示を改善しました（[#963](https://github.com/natumekazuki/WithMate/issues/963)）。送信履歴は必要な分を順次読み込み、取得失敗時は再試行できます。長い会話の追加読込と位置保持も調整しました。
- OpenCodeの質問で選択した候補を会話履歴で確認できるようにしました。Auxiliaryの追加後は、新しく追加した会話を送信先として選択します。
- Session Filesの削除候補計算、CopilotのDepth候補、およびCodexの専用処理がない通知について、問題を切り分けるための診断ログを追加しました（[#968](https://github.com/natumekazuki/WithMate/issues/968)、[#967](https://github.com/natumekazuki/WithMate/issues/967)、[#797](https://github.com/natumekazuki/WithMate/issues/797)）。Codexの未対応通知のログには、既知の認証情報を除去した後も、会話、tool結果、パスやその他の機密情報が含まれる可能性があります。共有前に内容を確認してください。
