# WithMate v7.0.1-preview.0

- Version: `7.0.1-preview.0`
- Tag: `v7.0.1-preview.0`
- 公開元: `feat/v7.0.1`
- 配布形式: Windows x64向け未署名NSIS installer

Session間の送受信と会話履歴の表示を改善し、報告された問題の切り分けに必要な診断情報を追加したpreviewです。`v7.0.0`からの変更を収録します。

## 変更内容

- 送信元の応答内に宛先付き送信カードを配置し、同じ応答内で複数の宛先へ送信した場合も、宛先と受付順を確認しやすくしました（[#953](https://github.com/natumekazuki/WithMate/issues/953)）。
- 受信したメッセージの送信元CharacterとSessionの色を表示します（[#958](https://github.com/natumekazuki/WithMate/issues/958)）。
- 開始済みのQueue項目に古い待機操作が残る表示を改善しました（[#963](https://github.com/natumekazuki/WithMate/issues/963)）。送信履歴は必要な分を順次読み込み、取得失敗時は再試行できます。長い会話の追加読込と位置保持も調整しました。
- OpenCodeの質問で選択した候補を会話履歴で確認できるようにしました。Auxiliaryの追加後は、新しく追加した会話を送信先として選択します。
- Session Filesの削除候補計算、CopilotのDepth候補、およびCodexの専用処理がない通知について、問題を切り分けるための診断ログを追加しました（[#968](https://github.com/natumekazuki/WithMate/issues/968)、[#967](https://github.com/natumekazuki/WithMate/issues/967)、[#797](https://github.com/natumekazuki/WithMate/issues/797)）。

## 互換性・利用上の注意

- 送信カードの本文内の位置は近似です。過去の送信で位置を復元できない場合は、その旨を表示します。
- 上記の診断ログ追加は原因修正ではありません。対象環境でログを確認し、原因と必要な対応を引き続き調査します。
- Codexの未対応通知の診断ログには、既知の認証情報を除去した後も、会話、tool結果、パスやその他の機密情報が含まれる可能性があります。ログを共有する前に内容を確認してください。
- Windowsのインストーラーは署名されていません。

## 検証結果

- Node.js 24.18.0の環境で、型検査と全464ファイルの自動テストが成功しました。変更テストの独立レビューも完了しています。
- Windows x64向けNSISインストーラーをビルドし、4種類のProvider実体とCLIの同梱を確認しました。同梱Electron上では、`koffi`と`node-pty`の読み込み、およびPTYの入出力を確認しています。
- 送信カードは模擬APIを使った描画と実SQLiteでの受付順を確認しました。実Providerを通す送信から保存までの専用E2Eは実施していません。
