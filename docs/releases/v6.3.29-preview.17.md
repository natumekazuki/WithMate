# WithMate v6.3.29-preview.17

対象タグ: `v6.3.29-preview.17`

preview.16以降の送信・応答表示の安定化、履歴スクロール、負荷改善、画像プレビュー再表示の修正、Homeの共通検索とセッション別Preview一覧を収録するソースプレビューです。Windows x64の未署名installerもローカル生成しました。

## 主な変更

- Main／Auxiliaryで連続して送信した応答を、確定履歴の到着待ちや次のターン開始時にも保持します。送信受付・本文更新・確定履歴の合流で表示行のidentityを維持し、応答枠の高さ変動と細かな本文更新による描画の揺れを抑えました（#845）。
- 会話の上端付近へスクロールすると古い本文を追加取得し、閲覧中の位置を保ちます。過去から新しい本文側へ戻る場合も必要な範囲を取得し、最新末尾で追従を再開します。閲覧範囲は最大180件とし、取得失敗時は本文を残してRetryできます（#861）。
- 履歴の失敗情報を検索する索引を追加し、不要な検索範囲を絞りました。Codex／Claudeの利用枠取得は成功後60秒間の要求を1件に集約し、Monitorの寸法読取と位置更新を分離しました（#857）。
- リンク付き画像の拡大操作が背後のリンクへ伝わり、画像プレビューが再表示される問題を修正しました（#859）。
- Homeの共通headerへ検索とNew Sessionを集約しました。検索語はRecent Sessions、Home内Monitor、Charactersで共有し、Sessionは保存済みMain Character名でも検索できます。入力確定後300msで適用し、取得中は直前の一覧を保持します。Clear Searchは即座に解除します（#860）。
- HomeへPreviewsタブを追加しました。開いているSessionと親Session別のFile Previewを表示し、既存Previewの前面化、右クリックまたはShift+F10による個別Close／親単位Close Allに対応します。Previewが0件でも開いているSessionは残り、Session名の変更を一覧へ反映します（#858）。

## 互換性と利用上の注意

- DB schemaの世代変更はありません。既存V6 DBへ失敗ターン検索用の索引を追加します。既存メッセージ・実行結果の保存形式は維持します。
- Session検索のCharacter名は保存済みMainの表示名を使い、catalogの改名には追従しません。AuxiliaryのCharacter名・会話本文・Character説明文は検索対象に含めません。独立MonitorとPreviews一覧へ共通検索を適用しません。
- Previewsは通常ファイル、live Git Diff、commit file、Git履歴diffを対象とし、chat artifactのsnapshot Diffは含みません。Close Allは対象親のPreviewだけを閉じ、Session本体や他Sessionには作用しません。
- Codex／Claudeの利用枠取得の60秒抑制はCopilotには適用しません。認証設定の変更時は既存の取得管理を破棄して再取得します。
- 共通検索の対象を視覚的に示す改善は[#865](https://github.com/natumekazuki/WithMate/issues/865)、test改善は[#863](https://github.com/natumekazuki/WithMate/issues/863)、[#864](https://github.com/natumekazuki/WithMate/issues/864)、[#866](https://github.com/natumekazuki/WithMate/issues/866)、[#867](https://github.com/natumekazuki/WithMate/issues/867)で追跡します。
- 送信後に表示identityを保った行が先頭可視位置にあると、履歴追加の成功応答が反映されない条件があります。通常の履歴行へ位置を変えると取得できます。保存データは保持され、修正は[#868](https://github.com/natumekazuki/WithMate/issues/868)で追跡します。Home headerが折り返した際の共通操作群の右寄せは[#869](https://github.com/natumekazuki/WithMate/issues/869)で扱います。
- #846の変更test抽出と全record審査は、前版で承認された後追いを継続します。固定baseと再開条件は[#846の追跡コメント](https://github.com/natumekazuki/WithMate/issues/846#issuecomment-6294857166)にあります。質問の自由入力欄での改行対応は[#862](https://github.com/natumekazuki/WithMate/issues/862)で別途扱います。
- 詳細は本版の[Desktop UI](https://github.com/natumekazuki/WithMate/blob/de62d803ec996dcaaa64e2f641c07b6aa778ee33/docs/design/desktop-ui.md)、[会話の読込み](https://github.com/natumekazuki/WithMate/blob/de62d803ec996dcaaa64e2f641c07b6aa778ee33/docs/features/long-session-performance.md)、[利用枠の更新](https://github.com/natumekazuki/WithMate/blob/de62d803ec996dcaaa64e2f641c07b6aa778ee33/docs/design/provider-usage-telemetry.md)を参照してください。
