# WithMate v7.0.0-preview.7

- Version: `7.0.0-preview.7`
- Tag: `v7.0.0-preview.7`
- 公開元: `feat/v7.0.0`
- 配布形式: Windows x64向け未署名NSIS installer

Session metadataの保守責務を分離し、Memory／Character Affectの専用機構を廃止したpreviewです。`v7.0.0-preview.6`からの変更を収録します。

## 変更内容

- SessionのTitleは目的・主題・担当対象を識別する短い名前、Descriptionは担当範囲と現在の状況として扱うよう、promptとMCP／CLIの説明を揃えました。進捗だけでTitleを書き換えず、目的や対象が変わった場合に更新します（[#951](https://github.com/natumekazuki/WithMate/issues/951)）。
- Characterの出力境界、tool実行前の応答、Session metadata保守の固定案内を短縮しました。Character定義、Workspace、Session Role、動的なmetadata・来歴・Timing等の情報は保持します。
- 一般Memory、Character Memory／episode、Character Affectを廃止しました。専用の画面・設定・MCP／CLI、Character context／Affect投影、背景実行、専用履歴・診断、暗号化添付管理も廃止対象です。

## 互換性・移行

- **更新後の初回起動時、Memory／Affect専用の保存データを退避なしで破棄します。** 専用テーブルの記録と関連情報、専用設定、管理対象の暗号化添付・keyringが対象です。破棄したデータを旧データから再取込・再生成することはありません。
- 通常Session／Auxiliary、会話・操作履歴、Character定義・資産、Timing、Session Graph、Repository Glossary、プロジェクト情報、共有DB・ファイルを保持します。V4元DB、元の取込ファイル、利用者がexportしたファイルは破棄対象外です。通常の履歴読取、Character editor、Prompt Template／Pickerも引き続き利用できます。
- 専用ファイルの削除とSQL更新は、一括で成功・取消される処理ではありません。途中で失敗すると起動を中止し、SQL更新をロールバックして次回起動で残りの処理を再試行しますが、既に削除したファイルは戻りません。以前のコードへ戻しても、破棄済みの記録・添付は復旧できません。
- Memoryによる過去の経験・判断の能動想起、Character episodeの継続、Affectの保存・時間減衰・afterglowは利用できなくなります。Character表現は定義と現在の会話文脈に依存します。通常履歴・Graph・Glossaryは残りますが、Memory／Affectと同じ体験を代替するものではありません。
- 廃止したMemory／Affect用MCP／CLIに互換入口はありません。外部で管理している指示・設定に旧入口への参照がある場合は、見直してください。

## 既知の注意

- 通常の`File → Exit`後に終了処理が反復し、プロセスとデータディレクトリのロックが残る問題がWindowsのソース版で報告されています（[#952](https://github.com/natumekazuki/WithMate/issues/952)）。この版には修正を含みません。

## 検証結果

- 型検査、変更に関連する自動テスト、Windows x64配布ビルドが成功しました。配布物のCLIとnative依存の読込も確認しました。
- 合成データを用いて、Memory／Affect専用データの破棄、通常データの保持、失敗時のロールバック・再試行を検証しました。Session／Graph／GlossaryのCLI・MCPでは、正常系と認可拒否・取消・回復の経路を確認しました。
