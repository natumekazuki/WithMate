# WithMate v6.3.29-preview.9

対象タグ: `v6.3.29-preview.9`

v6.3.29-preview.8に、Claude Agent、Files Pin、Mermaidの画像表示、Character定義の送信時更新などを追加するプレビューリリースです。

## 主な変更

- Claude Agentを公式Claude Agent SDKで利用できるようになりました。Settingsで有効化するとMain／Auxiliaryで選択でき、会話の再開、streaming、取消、承認・質問、画像入力、Skill、監査・usageの共通経路へ接続します。取消ではSDKの子process終了まで待機し、個別要求の取消や非対応Approval設定からの明示的な復旧も扱います（[#751](https://github.com/natumekazuki/WithMate/issues/751)）。
- Filesのファイル・フォルダをPinし、同じ階層内で優先表示できるようになりました。`Pinned Only`ではPinだけを一覧表示し、ファイルのpreviewやフォルダへの移動ができます。Pinは親Session内のMain／Auxiliaryで共有・保存され、別Sessionとは共有しません（[#770](https://github.com/natumekazuki/WithMate/issues/770)）。
- `.mmd`、Markdown、会話内のMermaid flowchartで、標準のimage nodeとHTML画像labelから画像を表示できるようになりました。通常のMarkdown画像と共通の読込経路を使用し、画像ごとの失敗表示、Reload、Zoom／Fit／表示移動を維持します（[#777](https://github.com/natumekazuki/WithMate/issues/777)）。
- Mermaid内のリンクを既存のファイルpreview・外部ブラウザー経路で開き、図内クリックによる画面全体の誤遷移を防ぎます。strict設定で除去されたリンク先は復元せず、開けない理由を表示します（[#768](https://github.com/natumekazuki/WithMate/issues/768)）。
- 画像・SVG・Mermaidの`Ctrl`＋ホイールによる倍率変更を既定5ポイント刻みにし、Settingsの`Preview Wheel Zoom Step`で1〜100ポイントを設定できるようになりました。拡縮ボタンは10ポイント刻みのままです（[#769](https://github.com/natumekazuki/WithMate/issues/769)）。
- 通常のMain／Auxiliaryで、active Characterの`character.md`変更を次の送信開始時に反映します。Characterのowner、表示名、説明、icon、theme、会話履歴とprovider threadは維持します。archived Characterは保存済み定義で継続します（[#775](https://github.com/natumekazuki/WithMate/issues/775)）。
- 各会話で採用したCharacter snapshotのアイコン参照を、system側のCharacter metadataへ`Icon:`として追加します。Character定義OFFやアイコン未設定時は省略し、画像添付やアクセス権限は追加しません。
- 新規Auxiliaryは、同じ親Session内でまだ使っていないCharacterを優先して選択します。Mainは除外し、未使用候補が尽きた場合は他Auxiliaryとの重複を許容して作成を継続します（[#749](https://github.com/natumekazuki/WithMate/issues/749)）。
- Sessionの取消終了待ちを`Canceling`として表示し、処理が解放されるまで次の送信を止めます。また、実行中の対象会話ではModel／Depthを変更不可にします（[#773](https://github.com/natumekazuki/WithMate/issues/773)、[#776](https://github.com/natumekazuki/WithMate/issues/776)）。
- Windows組み込みTerminalの`Ctrl+V`をclipboard貼り付けとして扱い、WSL起動後も利用できるようにしました。ファイルコピーの起動待ち・待機spinnerの処理を修正し、Markdownリンクは本文色と常時下線で表示するよう統一しました（[#772](https://github.com/natumekazuki/WithMate/issues/772)、[#771](https://github.com/natumekazuki/WithMate/issues/771)、[#774](https://github.com/natumekazuki/WithMate/issues/774)）。

## 互換性と利用上の注意

- Files Pin用にV6 DBへ`session_file_pins_v6`を追加します。新規・既存V6とも起動時のschema更新で作成し、Session本文などを作り直しません。Pinはpathへの目印であり、rename追跡や内容の固定は行いません。不存在・認可外のPinは理由付きで残し、明示的に解除できます。
- Character定義の更新は定義本文と関連metadataに限定します。active定義の欠落・読取り不能・validation失敗やowner欠落では送信を失敗させ、別Characterや古い定義へ黙って切り替えません。アイコン参照は画像の存在・現在の内容・agentからの読取可能性を保証しません。
- 画像の自動読込方針を統一し、ローカル画像は登録root内外のpath・file URL・UNCを扱います。相対pathは会話ではWorkspace、file previewでは元ファイルの親directoryを基準にします。画像表示に伴う通信や私的画像の表示が自動的に起こり得るため、出所を確認してください。汎用ファイル読込・directory列挙のroot認可やProviderの権限は拡張しません。SVGはpassiveな画像resourceとして扱い、inline DOMへ挿入しません。
- 画像の読込は表示面ごとに4並列・1 MiB chunkですが、容量・画素・総枚数・timeoutの上限は設けていません。大容量画像の全量保持によるメモリー負荷は残ります。Git commit previewの相対ローカル画像は解決しません。
- Claude Agentは既定で無効です。利用者本人の公式Claude CLIログインをSDKが使用し、WithMateは認証情報の読取り・コピーや独自OAuthを提供しません。SDKが参照する環境変数・設定によって認証先や課金経路が変わり得るため、自身の契約・設定を確認してください。認証失敗・利用枠不足時の別認証・モデル・Providerへの自動切替は行いません。
- ClaudeのApprovalは`Provider Controlled`のみです。quota残量、Codex専用sandbox／Reviewer／Speed、custom agent選択、background task一覧は提供しません。token／cache usageを契約残量や実請求額と同一視しないでください。SDK transcriptはWithMateの会話履歴と別にClaude側へ保存され、WithMateは管理・削除しません。
- preview.8までの変更・注意点は[前回のリリースノート](v6.3.29-preview.8.md)を参照してください。今回の仕様詳細は、収録実装commitに固定した[対応機能一覧](https://github.com/natumekazuki/WithMate/blob/f8757fff4cbd45af9923d77f21e55764e2f2f4c5/docs/design/coding-agent-capability-matrix.md)、[画像とリンク](https://github.com/natumekazuki/WithMate/blob/f8757fff4cbd45af9923d77f21e55764e2f2f4c5/docs/design/message-rich-text.md)、[Character Storage](https://github.com/natumekazuki/WithMate/blob/f8757fff4cbd45af9923d77f21e55764e2f2f4c5/docs/design/character-storage.md)、[Prompt Composition](https://github.com/natumekazuki/WithMate/blob/f8757fff4cbd45af9923d77f21e55764e2f2f4c5/docs/design/prompt-composition.md)、[Database Schema](https://github.com/natumekazuki/WithMate/blob/f8757fff4cbd45af9923d77f21e55764e2f2f4c5/docs/design/database-schema.md)を参照してください。

## 検証と未確認事項

- 収録機能は各branchのreview・関連testを経て統合しています。直近のFiles Pin、Mermaid画像、Characterアイコン参照の実機確認はユーザーから完了報告を受領しています。agentによる全機能の実機再確認を意味しません。
- リリース対象versionで`npm run typecheck`と`npm run build`は成功しました。全体testは`npm test -- --test-concurrency=4`で3,091成功・1 skip・失敗0です。rendererの一部chunkには500 kB超の警告があります。
- 全体testの初回失敗を切り分け、画面testの共有fixtureに不足していたPin一覧APIを補いました。alertなしの検証条件を維持し、失敗時にDOM全体を展開しない診断へ変更しています。修正後に関連test、変更testのread-only審査、test型検査、全体testを確認しました。製品コードを成功扱いにするfallbackやtest条件の緩和は追加していません。
- Claudeの追加修正では実SDK接続の検証ログとWindows配布物の生成・同梱確認を確認済みですが、製品Window全体、macOS／ARM64を含む全機能・全配布環境の実機確認は完了していません。今回の公開操作ではこれらの検証を拡大していません。
- Markdown内MermaidのFindがSVG内部のCSSにも一致する問題は未修正です（[#767](https://github.com/natumekazuki/WithMate/issues/767)、対応時期未定）。また、Open Diffのstale応答testの検出力に関する非ブロッカーを[#777](https://github.com/natumekazuki/WithMate/issues/777#issuecomment-5971260656)で追跡しています。未修正項目を完了扱いせず、通常の後追い対応として分離しています。
- 対象Milestoneと未割当ての関連Issueを確認し、今回の範囲は統合済み変更に限定しています。Issueの未完了状態とソースへの収録・preview公開は区別し、preview公開ではIssue／Milestoneを一括Closeしません。
- このリリースはversion、repository内リリースノート、Gitタグによるソースのpreviewです。新しいinstallerの作成・配布やGitHub Releaseの作成は行わず、既存のリリースタグも変更しません。
