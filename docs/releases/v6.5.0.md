# WithMate v6.5.0

- Version: `6.5.0`
- Tag: `v6.5.0`
- 公開元: `master`

Memory・Character Affectを通常会話から独立して管理する正式版です。v6.5.0の各previewの変更に、通常Memory添付のファイル認可と、作業中のCharacter表現・Affectの反映指示を加えています。

## 変更内容

### MemoryとAffectの背景管理

Character Memory・対象Memory・Character Affectを、保存済みのMain／Auxiliary会話を材料に独立して実行します。Settingsの`Background Execution`で用途ごとのProvider・Model・Depth、対応するApproval／Reviewer／Sandboxと登録指示を選択できます。通常会話のthreadや応答待ちとは分離し、同じ元会話・用途の背景threadを継続します。

背景Agentは用途ごとに許可されたMemoryを参照・登録・訂正・忘却し、Affectはinspect・appraise・correctを扱います。元Mainの共有Session Graphと許可checkoutのGlossaryは参照専用です。別Agentへの委譲、別Sessionや追加Agentの実行、常駐・定期実行、対話・承認要求、用途外の変更・外部送信を禁止する標準指示を加えました。専用管理操作の権限は用途別bindingで制御します。

体験と知識を別の目的として整理するよう標準指示を更新しました。知識や好みを抽出しただけで元の体験を不要とせず、短くまとめても出来事とCharacter自身の受け取りを残します。

### Memoryの登録・参照とファイル認可

- MCPとCLIの両方で、Memoryの`entries`・Character episodeの`episodes`による一括登録を提供します。項目ごとの保存済み・失敗・結果不明・未実行を返し、途中失敗でも確定済み項目を保持します。
- 通常Main／Auxiliaryの入力前の自動Memory検索・注入をなくし、Agentが必要時にMCP／CLIで想起します。Character Affect Contextの供給は維持します。
- Projectの参照・保存を既存storageが解決する正規IDへ統一し、未登録Projectの初回保存と複数targetの認可・解決を整理しました。
- 通常Sessionの添付取込と明示復元を、実SessionのWorkspace・許可Additional Directories・SessionFolder内に限定しました。Auxiliaryは自身の設定と親MainのSessionFolderを使います。[#578](https://github.com/natumekazuki/WithMate/issues/578)の対応です。
- 背景の対象Memoryは添付を登録でき、三用途は必要時に許可済み添付をSessionFolder内の`memory-exports/`へ復元できます。通常Sessionの復元先へ権限を拡張しません。
- file scopeの欠落、root外・symlink／junction経由の範囲外実体を拒否します。復元はローカルwriteとして扱い、plan／Codex read-onlyでは拒否し、既存出力を上書きしません。

### Characterの声とAffect

技術説明・進捗・発見・見立ての訂正・意見不一致・最終報告にも、Character定義に沿った声・距離感・着眼点・反応を反映する指示を明確にしました。発話量と個性の強さを分け、一律に口癖や感想を増やしません。[#933](https://github.com/natumekazuki/WithMate/issues/933)の対応です。

Affectは基本の人格と声を保ち、話し方・反応・発話量・関心の表し方へ反映します。技術判断の根拠・確度、事実、操作権限、検証結果は変えません。会話や非公開の作業記録と、コード・PR本文等の再利用成果物の文体を分けます。

注入の設定・条件、保存済みCharacter snapshot、AffectのJSON投影と送信経路は維持します。背景三用途も通常と共通のprompt構成を使います。

### 表示と診断

- Memory Reviewの対象名・アイコン・絞り込み・一覧を整理しました。Settingsではセクションと設定グループを個別に開閉できます。
- 無効ModelとOpenCodeサービスを背景の候補・開始準備にも適用し、保存選択を保持したまま再有効化や別Modelの選択を案内します。
- Codexの画像確認・待機・会話圧縮・子Agent活動をOperationsへ保存・復元します。子Agent活動は操作履歴であり、Tasksの実行管理とは分離します。
- Memory／Characterの入力拒否でtool・field・期待条件を返します。背景Agentの実行終了と各操作の成否・保存効果を分け、診断ログへ記録します。

## 互換性・利用上の注意

- 背景三用途は初期状態で未設定です。利用する用途のProvider・Model等を設定してください。未設定用途を通常会話や別用途のModelへfallbackしません。
- 編集済みの背景登録指示は空文字列を含め自動で置換しません。新しい標準本文を使う場合は、各用途の`Use Preset`を選択してください。
- 既存Memory・Affect・Graphと単件／一括入力を保持します。v6.3系からの更新では起動時のV6 schema ensureでAuxiliary出典等を反映します。SQLiteの`user_version`は6のままです。preview.4からの追加DB migrationやデータ再生成はありません。
- 添付のfile認可はProviderのnative file操作とは別です。Providerの全FS権限やElectronのOS権限からMemoryの許可範囲を拡大しません。trusted `local_user`のoperator操作はSession root限定の対象外です。
- 本文・添付サイズ・quota、Provider・通信の制限は維持します。背景thread・未開始処理・前回失敗はアプリ再起動をまたいで復元せず、自動で一括再送しません。
- `completed`はAgent実行の正常終了であり全件保存の証明ではありません。背景の操作診断は`userData/logs/background-failures.jsonl`を参照してください。
- ソース・tag・repository内ノートを公開し、Windows x64向け未署名NSIS installerをローカル作成します。GitHub Releasesへの配布物アップロードと自動インストールは行いません。

- 最終修正差分でproduction・script・testの型検査、SQLite owner・依存境界checkが成功しました。
- 全体testは3,828件成功、失敗0、skip 1でした。通常・背景MCP／配布CLI、暗号化objectとstorage Worker、root外・junction拒否、Main／Auxiliaryとread-only／planを含みます。
- 変更test全7件・全7遷移とproduction差分の独立read-only reviewを完了し、必須修正・統合ブロッカーはありませんでした。
- Codex `gpt-6.1-sol`／mediumで、固定Character・Affect・履歴・tool条件の3例を変更前後で生成しました。6応答は必要情報・未実行状態・再利用本文の境界を保持しました。変更前からCharacterの声が出ており、全般的な個性強化の実証とは区別しています。
- `6.5.0`のrenderer・PDF reader・Main・CLI buildが成功しました。既存のchunk size警告があります。
