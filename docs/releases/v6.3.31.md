# WithMate v6.3.31

- Version: `6.3.31`
- Tag: `v6.3.31`

`v6.3.31-preview.0`の運用で問題がないとのユーザー確認を受け、同じアプリケーションコードを正式化しています。

## 変更内容

- チャットのローカルファイルリンクで、Sessionの作業範囲外でも実在するファイルには`Copy File`を表示します。送信待ちのメッセージでも同じメニューを利用できます。
- 通常File Previewの読込み、Reload、ファイル操作、相対リンクの基準を実ファイルのcanonical pathへ揃えました。Additional Directoryを解除しても、開いているPreviewは継続して利用できます。
- 独立Previewの通常ファイル操作は、そのWindowに紐付いたcanonical fileを対象にします。元のroot情報はGit投影の対象識別に使い、rootのリンク先変更で別ファイルを通常Previewとして読まないようにしました。
- HTMLの相対資源を実際のディレクトリ構造に沿って解決し、親ディレクトリへの参照が範囲内の別ファイルへ対応する不具合を修正しました。資源は捕捉したroot内に限定し、Git資源は選択commitから読みます。
- 添付候補と送信直前の再検証では、ファイルと作業rootの実体パスで範囲を判定します。junction／symlinkの置き場所だけでは範囲外の実体を添付できません。リンク先のディレクトリも作業範囲へ追加すると添付できます。

## 互換性・利用上の注意

- v6.3.30およびv6.3.31-preview.0からデータ形式やmigrationの変更はありません。
- File Explorer／Pin／Gitの対象範囲と、エージェントへ渡す権限は変更しません。通常PreviewとCopy Fileによる作業rootの追加はありません。
- HTMLの`/`で始まる資源pathは元ファイルのvolume root基準で解決し、捕捉root外なら拒否します。相対参照は元のディレクトリ構造を保ちます。
- Windows x64向けの未署名installerです。
