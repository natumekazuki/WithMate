# WithMate v6.3.29-preview.6

対象タグ: `v6.3.29-preview.6`

v6.3.29-preview.5以降の統合済み変更を公開するプレビューリリースです。画面パーツごとの段階読込、Mermaidファイルのプレビュー、SessionFolderの作成、Model Catalog反映時の最終利用時刻を改善し、Codex SDKを更新します。

## 主な変更

- Sessionの基本情報と会話を独立して取得し、会話の読込中でも取得済みのheaderやFilesを表示します。Homeの一覧もapp state全体の取得を待たずに表示し、Settingsは設定draft、Model Catalog、Diagnosticsを独立して読み込みます。読込中は共通のspinnerとaccessible statusを使い、失敗したパーツだけを再試行できます（[#744](https://github.com/natumekazuki/WithMate/issues/744)）。
- Sessionの設定・Model Catalogの取得失敗に再試行導線を追加しました。承認・質問への応答とlive更新が競合した場合、古い再取得結果で新しい要求や終了状態を上書きしないようにしました。
- `.mmd`ファイルをMermaid図としてプレビューできます。Sourceへの切替、Find、選択文字列のCopy／Quoteにも対応し、図の構文エラーは表示上のエラーとして扱います。
- Main Sessionの新規作成時は、選択したworkspaceの種類やCharacter authoring経由かどうかにかかわらず、SessionFolderを準備してから保存します。未作成の既存Sessionでは、Providerへpathを渡す前に準備します。
- Codex SDKと対応するCLIを`0.156.0`から`0.159.0`へ更新しました。
- Model Catalogのimport／resetに伴う内部metadata移行で、Main／Auxiliaryの`updatedAt`とMainの`last_active_at`を保持するようにしました。model／depthの正規化やthread resetが必要な場合も、カタログ反映だけを理由に全SessionのUpdatedやHomeの並び順を変えません。

## 互換性と利用上の注意

- 今回の差分に新しいDB migrationや既存の保存形式の変更はありません。preview.3以前から更新する場合は、[preview.4の保存・移行に関する注意](v6.3.29-preview.4.md#互換性と利用上の注意)も確認してください。
- 段階読込中の未取得データは正常な空データと区別します。会話全体を取得する前に、そのprojectionを使って会話を保存・送信しません。取得済みの内容や編集中の設定draftは、無関係な再試行で初期化しません。
- SessionFolderは新しいSession IDに対して排他的に作成します。既存の同名directoryやSession recordを上書き・再利用しません。準備中のfilesystem I/OはProvider操作のcoordinator外で行い、保存時に起動設定とstorage identityを再検証します。
- 最終利用時刻の保持修正は、今後のカタログ反映による意図しない更新を防ぐものです。過去の反映で既に変更された時刻を復元する処理は含みません。通常の会話や明示的なSession操作による時刻更新は維持します。
- 現行の契約は[Desktop UI](https://github.com/natumekazuki/WithMate/blob/7f39a7be7f5e1bf8c0ffbaa4568821b864b5812d/docs/design/desktop-ui.md)、[Session Local Files](https://github.com/natumekazuki/WithMate/blob/7f39a7be7f5e1bf8c0ffbaa4568821b864b5812d/docs/design/session-local-files.md)、[Model Catalog](https://github.com/natumekazuki/WithMate/blob/7f39a7be7f5e1bf8c0ffbaa4568821b864b5812d/docs/design/model-catalog.md)を参照してください。
