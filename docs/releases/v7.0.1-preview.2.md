# WithMate v7.0.1-preview.2

`v7.0.1-preview.1`から、操作の承認、親子Sessionの会話と実行設定、失敗時の再送を更新しました。

## 変更内容

- Settings に `WithMate Auto Review` を追加しました。既定は `Off` です。有効にすると、Copilot／OpenCode の `Provider Controlled` で発生した対象の承認要求を、選んだ Claude または Codex のモデルで審査できます。保留中の操作と審査に必要な保存済みの会話が、選んだ審査先に送られます。審査用の会話は元の実行Turn内でのみ使い、通常のSessionや履歴としては保存しません。審査できない場合や本人の判断が必要な場合は手動承認に戻ります。
- Mainの会話を初期スレッドと作成済みの直属子Sessionごとのスレッドに切り替えられるようになりました。保存済みの発言や送信カードを選んで返信すると、送信後に返信元を確認できます。スレッドの切替や返信元の選択だけでは送信先は変わりません。
- 失敗が確定したTurnの保存済み開始入力を `Resend` で再実行できます。今の下書きには影響せず、待機中の再送は通常の予約と同じように編集・並べ替え・取消ができます。
- 新しい子Sessionは作成元の実行Turnから実行権限を引き継ぎます。異なるProviderで同等の制限を保てない場合は作成できません。親子間の通常送信では、受付時の宛先の承認・Sandbox・審査役設定を使用します。Session MCP／CLI の `create_child` と `enqueue` は権限の上書き指定を受け付けなくなりました。子のCharacterの自動選定では、他の候補がいれば直接の親と同じCharacterを除外します。
- 送信文と応答待機は受付後に表示し、すぐに開始する送信は待機キューに一瞬だけ現れなくなりました。開始を待つ予約には従来どおりキュー操作を表示します。
