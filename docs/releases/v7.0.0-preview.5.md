# WithMate v7.0.0-preview.5

- Version: `7.0.0-preview.5`
- Tag: `v7.0.0-preview.5`
- 公開元: `feat/v7.0.0`

親からCodex子Sessionを作る際にReviewerを選択できるpreviewです。`v7.0.0-preview.4`からの変更を収録します。

## 変更内容

- Session MCPとbound CLIの`get_catalog`で、Codex子作成時のReviewer候補を`options[].reviewers`から確認できます（[#945](https://github.com/natumekazuki/WithMate/issues/945)）。
- `create_child`に任意の`codexReviewer`を指定でき、`on-request`と`auto-review`の組合せで子を作成できます。選択値は作成結果の`executionOptions`、子の保存設定、初回以降の通常依頼へ引き継がれます。

## 互換性・利用上の注意

- Reviewerを省略した既存の作成要求は、従来どおり`user`で作成します。非対応Providerへの指定や不正な値は、理由を返して作成を拒否します。
- Reviewerの選択は操作権限や個別承認の追加付与ではありません。通常送信`enqueue`の引数、既存Sessionの設定変更、Steerの契約は変更しません。
- DB形式・migrationに変更はありません。既存データとリリース済みpreviewの継続性を維持します。
- Windows x64向け未署名NSIS installerを用意します。インストールや起動中アプリの置換は自動で行いません。
