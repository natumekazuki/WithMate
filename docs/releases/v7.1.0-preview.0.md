# WithMate v7.1.0-preview.0

`v7.0.1`から、ローカル Pull RequestsとSessionごとの固定指示を追加し、Session Graphを廃止しました。

## ローカル Pull Requests

- GitリポジトリのSessionからローカルPRを開き、固定されたcommitの差分をレビューできます。全体・前回版との差分、ファイルや行への指摘、下書き、再提出に対応します。選んだ指摘は同じリポジトリの既存Sessionへ送れます。GitHubへの投稿や同期は行いません。
- 提出版に含まれる `.withmate/ci.yml` のコマンドを独立したcheckoutで実行し、版ごとのChecksとログを確認できます。コマンドはWithMateのOS権限で動作し、Providerのsandboxではありません。
- GUIで提出commitとmerge先commitを承認した後、通常のGit mergeを実行できます。新しい版の提出やmerge先の更新後は再承認が必要です。CI成功はmergeの強制条件ではありません。Gitの設定に従い、外部のmerge driverやfilterが実行される場合があります。

## Session Instructions

- Main／Auxiliaryごとに固定指示を設定できます。指示は次に開始するTurnへ渡され、実行中のTurnには遡って反映されません。Session間の共有や継承はありません。
- 指示はUTF-8で最大8,192バイトです。画面のほか、自Sessionに対するMCP／CLIから取得・全文置換・解除できます。

## Session Graphの廃止

- Session Graphの画面、MCP、CLIと保存機能を廃止しました。旧Graph MCP／CLIを呼び出す利用者側の設定や指示は更新してください。
- **更新時に、保存済みのSession Graph専用データはバックアップなしで削除されます。** 旧版に戻しても削除済みデータは復元できません。通常のSession、会話履歴、Coordinationおよび利用者のファイルはGraph廃止による削除対象ではありません。
