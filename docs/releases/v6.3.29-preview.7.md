# WithMate v6.3.29-preview.7

対象タグ: `v6.3.29-preview.7`

v6.3.29-preview.6に、Session Windowのタブ付き組み込みTerminalと関連するレイアウト改善を追加するプレビューリリースです。

## 主な変更

- Sessionの下部パネルを`Prompt / Terminal`で切り替えられます。xterm.jsとnode-ptyを利用し、WindowsではPowerShell、macOSではzshを親SessionのWorkspaceから起動します（[#740](https://github.com/natumekazuki/WithMate/issues/740)）。Linuxの組み込みTerminalは未対応です。
- タブごとに独立した端末を保持します。Promptへの切替、パネルの折りたたみ、Main／Auxiliaryの切替では端末を終了せず、Promptのdraftと端末出力を維持します。生存中のタブを閉じる時は確認し、最後のタブを閉じるとパネルを畳みます。自然終了・起動失敗は結果を表示し、出力を残します。
- 下部パネルの高さはPromptとTerminalで共有し、splitterのdragと上下矢印キーで調整できます。中央領域が160px未満になる場合は状態を保持したまま非表示にし、高さを戻すと再表示します。狭いWindowでの高さ補正と最大化時の余白も改善しました。
- 既定の切替shortcutはWindows／Linuxの`Ctrl+Shift+T`、macOSの`Cmd+Shift+T`です。Settingsで変更できます。端末入力中の`Ctrl+C`と`Escape`はシェルへ渡し、会話の送信・取消shortcutとは分離します。
- Workspaceの`Terminal`は組み込み端末を開きます。従来の外部起動は`Open External Terminal`で利用でき、Session Folderの外部Terminal操作は変更しません。
- Home一覧の部分更新では、開いているSessionの新しいsummaryを反映しつつ、取得済みページの並び順とcursorを保持するようにしました。

## 互換性と利用上の注意

- 新しいDB migrationや既存の保存形式の変更はありません。preview.6までの変更・注意点は[前回のリリースノート](v6.3.29-preview.6.md)を参照してください。
- 組み込みTerminalはアプリのOSユーザー権限で動作し、Providerのapproval／sandbox設定とは独立します。Workspaceは開始directoryであり、シェルのアクセス制限ではありません。
- タブ、process、端末出力、入力mode、パネルの高さはWindow内の状態であり、Windowを閉じた後や再起動後には復元しません。端末の入出力は会話・監査ログへ保存しません。
- TerminalのIPCでは送信元Windowと親Sessionの所有関係を確認し、cwdとshellはMain側で決定します。Window破棄、Session削除、アプリ終了時には対応するPTYを解放します。
- 配布buildではnode-ptyのnative moduleとConPTY付随ファイルを含めます。Windowsでsource buildする環境にはMSVCのSpectre-mitigated librariesが必要です。
- リリース時の仕様は[Desktop UI](https://github.com/natumekazuki/WithMate/blob/99dd2c788f7575a1e3b569456d2716780c4c269d/docs/design/desktop-ui.md)、[Electron Window Runtime](https://github.com/natumekazuki/WithMate/blob/99dd2c788f7575a1e3b569456d2716780c4c269d/docs/design/electron-window-runtime.md)、[Distribution Packaging](https://github.com/natumekazuki/WithMate/blob/99dd2c788f7575a1e3b569456d2716780c4c269d/docs/design/distribution-packaging.md)を参照してください。
