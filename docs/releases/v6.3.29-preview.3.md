# WithMate v6.3.29-preview.3

v6.3.29-preview.2以降のNew Session、Recent Sessions、Monitor、Auxiliary実行を更新するプレビューリリースです。

## 主な変更

- Homeの`New Session`に`Cancel`を追加しました。入力中の意図しない終了を防ぐため、このdialogはbackdrop clickや`Escape`では閉じません。開始できない状態でも`Cancel`から作成せずに戻れます。
- Homeの`Recent Sessions`に表示する更新時刻を、内部field名と生のISO値から、英語の曜日を含むローカル時刻へ変更しました。並び順と保存値は変更していません。
- Home内と独立WindowのMonitorで、初期表示とRunning／Stopped領域の描画を安定化しました。Session Window内に別のMonitorを追加する変更ではありません。
- Auxiliary Composerからの送信時に、Storage Workerへ実行callbackが渡って`DataCloneError`になる問題を修正しました。draft consume成功後にMain processでturnを実行する既存の責務分離は維持しています。
- 開発・保守用の文書を現行仕様へ整理し、不要になった作業計画・旧仕様の資料を削除しました。製品データはこの文書整理の対象ではありません。

## 互換性と利用上の注意

- v6.3.29-preview.2からの更新で、新たな保存形式変更やデータ移行はありません。
- v6.3.29-preview.1以前から直接更新する場合は、[preview.2のCompanion専用データ削除に関する注意](v6.3.29-preview.2.md#互換性と利用上の注意)を更新前に確認してください。
- 処理中バブルを生成中のassistant応答枠へ統合する変更（Issue #742）は、このプレビューには含めていません。

## 検証

- `npm run typecheck`: 成功。renderer、Electron、testの型検査と境界checkを含みます。
- `npm run build`: renderer・Electronともに成功。rendererの一部chunkで500 kB超の警告があります。
- `npm test`: 2,891件中2,890件成功、1件skip、失敗なし。
- Homeの`New Session` dialogはブラウザーで1180×820と640×480の描画を確認しました。Electron実機での別Window切替・paste操作、provider実機、他OSでの動作は今回確認していません。
