# WithMate v7.0.0-preview.3

- Version: `7.0.0-preview.3`
- Tag: `v7.0.0-preview.3`
- 公開元: `feat/v7.0.0`

Provider選定方針とGit Worktree配置ルールを、Session MCPとbound CLIから管理できるpreviewです。`v7.0.0-preview.2`からの変更を収録します。

## 変更内容

- Provider／Modelの選定基準、Depth・Approval・Sandboxの目安、契約経路の優先順と利用条件を端末設定として取得・登録・更新・解除できます。子Sessionの作成や実行設定の選び直しでは、保存した方針と対象Provider／Workspaceの実際のModel Catalogを参照します（[#926](https://github.com/natumekazuki/WithMate/issues/926)）。
- Provider quotaは、既存telemetryの取得状態・取得日時・値を読取専用で返します。この照会で再取得は行わず、未観測は`null`のまま返します。未取得・古い情報から無料・無制限・利用可能とは判断しません。
- Worktreeの端末共通ルートと、repository別の分類・命名・配置ルールを取得・登録・更新・解除できます。同じGit repositoryのlinked worktreeは共通の設定を参照し、branchに登録済みのWorktree、新規作成候補、設定不足を区別して返します（[#943](https://github.com/natumekazuki/WithMate/issues/943)）。
- MCPとCLIに同じ7操作を追加しました。単発の作成先指定は保存せず、照会だけではGitや設定を変更しません。未設定時にSession FolderやCrew Folderへ自動的に切り替えません。

## 互換性・利用上の注意

- 設定は既存の`app_settings`へ保存し、新しいDBテーブルやmigrationは追加しません。既存データと公開済みのSession・Turn・権限契約を維持します。
- 初期状態では方針・配置ルールは未設定です。恒久設定の更新はユーザーの明示指示に従い、単発の指示・評価・提案から自動登録しません。アプリ設定の全リセットではこれらの設定も解除します。
- 設定は判断材料であり、自動的なProvider切替や課金経路の判定は行いません。外部Providerのルールファイルや認証情報も変更しません。
- Worktreeの解決は配置先の照会です。実際の作成・削除・branch操作は行いません。
- Windows x64向け未署名NSIS installerを用意します。インストールや起動中アプリの置換は自動で行いません。
