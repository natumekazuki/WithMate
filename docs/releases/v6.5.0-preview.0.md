# WithMate v6.5.0-preview.0

- Version: `6.5.0-preview.0`
- Tag: `v6.5.0-preview.0`
- 公開元: `feat/v6.5.0`

MemoryとCharacter Affectの背景実行を含むプレビューです。v6.3.32までのmasterの変更を取り込み、ソースをbranchとtagで公開します。

## 変更内容

### MemoryとCharacter Affectの背景実行

Character Memory、対象Memory、Character Affectを通常の会話とは独立して呼び出します。Main／Auxiliaryの保存済み会話を材料に、背景側が許可された履歴・Memoryを読み、用途別のMCP／CLI操作で直接登録します。通常会話のthreadや実行状態を変更せず、会話の応答を待たせません。

Settingsの`Background Execution`で、三用途それぞれのProvider・Model・Depth、対応するApproval／Reviewer／Sandbox、登録指示を設定できます。本文未設定時だけ用途別presetを使い、編集済み本文と空文字列はそのまま使用します。

Memory二用途は別々に頻度を設定でき、既定は各5 Turnまたはidle 5分です。Affectは会話の終端保存後に独立して処理します。用途未設定の場合は呼び出さず、通常会話や別用途のModelへfallbackしません。

### Model無効化の共通適用

`Models`で無効化したModelとOpenCodeサービスは、背景三用途でも選択候補から除外します。保存済みのModel／Depthは変えず、無効な現在値を`Disabled`と表示して、再有効化または別Modelへの変更を案内します。

背景呼出しの開始準備でも同じ設定を確認し、無効ならProvider呼出しへ進みません。再有効化は次の準備へ反映します。設定変更で準備済み・実行中の背景処理を取り消すことはありません。

### Memoryの能動的な想起

通常Main／Auxiliaryの入力前に行っていた関連Character Memoryの検索とsystem promptへの自動注入を廃止しました。必要な記憶はAgentがMemory MCP／CLIで能動的に参照します。Character Affect Contextの取得・注入は維持します。

### masterからの取り込み

- 送信待ちメッセージを、予約の識別子・順序・実行設定を維持したまま編集できます。
- ProviderごとのModel、OpenCode接続先サービスの有効・無効設定、検索、一括切替、Undo、開いている候補への再有効化反映を含みます。
- Character promptの重複説明とIconパス注入を整理し、Character本文と画面用Iconを維持します。
- 通常File Preview／Copy Fileの対象とエージェントの作業範囲を分離し、HTML相対資源と添付の実体パス判定を修正しました。
- Session GraphのTopic内余白と背景、共通Checkbox表示を調整しました。

## 互換性・利用上の注意

- 背景三用途は初期状態で未設定です。利用する用途のProvider・Model等をSettingsで設定してください。既存会話のModel設定は自動変更しません。
- 背景の同時実行数にアプリ独自の上限や待機queueを設けていません。Providerの利用制限・課金は通常の接続条件に従います。
- アプリへ承認要求・質問が届いた背景呼出しは、画面や回答待ちを作らず、その呼出しを失敗として終了します。Provider内部の自動審査と通常のsandbox・管理者policyは維持します。
- 失敗は`userData/logs/background-failures.jsonl`へ記録します。未設定による非実行と正常な保存対象なしは失敗としません。
- 記録はbest effortです。再起動前の未開始分の一括処理や自動再送は行わず、後続処理の失敗・取消でも先行確定済みの登録を保持します。
- Auxiliary由来のMemory出典とAffectの会話ownerを区別して保存します。起動時のschema ensureで既存V6へ必要な列・制約を反映し、既存Memory本文とMainのAffect記録を保持します。Affectの関連tableは既存行をコピーして同一savepointで再構築します。SQLiteの`user_version`は6を維持します。
- このプレビューはソース公開です。別端末ではtagを取得し、`npm ci`の後に`npm run electron:start`でbuild・起動できます。Providerの認証は各端末で用意してください。
