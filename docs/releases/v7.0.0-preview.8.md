# WithMate v7.0.0-preview.8

- Version: `7.0.0-preview.8`
- Tag: `v7.0.0-preview.8`
- 公開元: `feat/v7.0.0`
- 配布形式: Windows x64向け未署名NSIS installer

Agentへ渡す固定promptを必要な文脈へ絞り、通常Exitの終了処理を修正したpreviewです。`v7.0.0-preview.7`からの変更を収録します。

## 変更内容

- Session metadataの現在値と常時保守指示をpromptから外しました。Title／Descriptionを取得・更新するMCP／CLIと保存・認可の契約は維持します。
- 会話のTiming集計を外し、Turn開始時のUTC offset付き現在日時だけを渡すようにしました。Settingsの`Current Date`で有効・無効を選べます。従来の日時情報のON／OFF設定は引き継ぎます。
- 入力の来歴を送信元・操作等の出所データへ整理し、Characterの出力境界とfolder用途の案内を短縮しました。Tool Call Presenceの固定指示と設定は廃止しました。
- 通常の`File → Exit`で終了処理が反復し、プロセスとデータディレクトリのロックが残る問題を修正しました（[#952](https://github.com/natumekazuki/WithMate/issues/952)）。
- preview.7のリリースノートを、利用者向けの変更・更新時の注意・検証結果へ整理しました。preview.7のタグと配布内容は変更していません。

## 互換性・更新時の注意

- 通常Session／Auxiliary、会話・操作履歴、Character定義・資産、実行管理のTurn時刻、保存された来歴、Session Graph、Repository Glossaryは保持します。promptの簡素化は、これらの保存・認可契約の廃止ではありません。
- **preview.6以前から更新する場合、初回起動時にMemory／Affect専用データを退避なしで破棄します。** preview.7から継承する変更です。専用記録・関連情報・設定・管理対象の暗号化添付・keyringが対象で、通常Session／履歴／Character／Graph／Glossary／共有資産、V4元DB、元の取込ファイル、exportは破棄対象外です。
- 専用ファイル削除とSQL更新は一括処理ではありません。失敗すると起動を中止し、SQL更新をロールバックして次回起動で残りを再試行しますが、削除済みファイルは戻りません。旧版のコードへ戻しても破棄済みデータは復旧できません。Memory／Affectの機能喪失と廃止入口については[preview.7の更新時の注意](v7.0.0-preview.7.md#互換性移行)も参照してください。

## 検証結果

- 関連自動テストと型検査が成功しました。prompt生成、4Provider adapter、設定の保存、実行・履歴の維持、終了処理の再入を確認しています。
- 分離した合成データのWindowsソース版で、通常Exitによるプロセス終了・ロック解放と、同じprofileからのWindow集合・履歴・Auxiliary draftの復元を確認しました。
- 本番Settings componentの分離描画で、Current DateをOFFにして保存できることを確認しました。
- Windows x64配布ビルドが成功しました。配布物のMain・renderer・PDF readerと生成出力の一致、同梱CLIのhelp／schema、native依存の読込を確認しました。
