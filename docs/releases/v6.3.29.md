# WithMate v6.3.29

対象タグ: `v6.3.29`

v6.3.28以降の変更をまとめた正式版です。

## 主な変更

- Session Graphを追加しました。MainとAuxiliaryのagentが要求・制約・判断・活動・観測・未解決事項と関係をMCP／CLIで共有し、会話と並べて、または独立Windowで話題や担当、更新状況を確認できます。会話の自動要約は行いません。
- Claude AgentとOpenCodeをProviderに追加し、Codexを公式CLIのApp Server接続へ移行しました。4 Providerのモデル候補を各Providerから取得し、検索して選択できます。質問・承認の会話内表示、通知、回答を改善しました。実行中の通常送信は次ターンとして予約し、待機順を変更できます。Codexへの追加入力は別操作です。
- HomeとMonitorを整理し、Main／Auxiliaryの実行・入力待ち・未読状態を確認しやすくしました。会話は必要な履歴をスクロールで読み込み、全履歴の検索とブックマークへ移動できます。
- Workspaceの組み込みTerminal、Git履歴と比較、FilesのPinを追加しました。Git履歴と比較は読み取り専用です。Mermaidや画像の拡縮、PDF・HTMLのプレビュー、ファイル貼付時の同名ファイルの再利用・別名保存・置換にも対応しました。
- Additional Directoryを親Session内で共有し、Settingsから条件を指定してSession Filesの容量確認と削除ができます。Character定義の変更は次の送信時に反映します。

## 互換性と利用上の注意

- Companionを廃止しました。更新後の初回起動時、管理対象DBとバックアップ内のCompanion専用記録、および専用ファイル・SessionFolder・Git namespaceを削除します。必要な専用データは更新版の起動前に別途バックアップしてください。通常Sessionや共有Memoryなどは保持します。
- DBはV6を継続し、通常会話・Memory・保存済みAffectを保持します。旧Audit専用詳細、手管理Model Catalog、未処理のAffect候補・retryは削除されます。Auxiliaryだけに登録していたAdditional Directoryは共有一覧へ移行されないため、必要なものは再登録してください。実ファイルは削除しません。
- OpenCodeはPATH上の公式CLI `2.2.5`と既存のnative認証を使用します。以前のpreviewで設定したWithMate専用OpenCode API keyは削除され、自動移行されません。認証をnative側または起動環境に設定してください。preview.20／21の専用DBの会話は公式export／importで移行します。移行に失敗した場合は新規会話へ自動切替せずエラーを表示します。
- 組み込みTerminalはWindows／macOSに対応し、OSユーザーの権限で動作します。Workspaceは開始場所でありアクセス制限ではありません。端末の入出力は会話・監査ログへ保存せず、Windowを閉じると端末状態は復元されません。
- HTMLプレビューは外部通信を行う場合があり、入力内容が外部へ送信される可能性があります。File System Access APIの選択済みhandleによる読書きは未対応です。画像の自動読込みでも通信やローカル画像の表示が起こり得ます。
- Clean Session Filesはごみ箱を経由せず完全削除します。会話履歴やPinは残りますが、削除したファイルは開けなくなります。同名ファイルのReplaceも同じpathを参照する過去の会話に影響します。
