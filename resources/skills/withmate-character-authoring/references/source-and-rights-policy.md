# Source And Rights Policy

## Source Order

full authoring、source に依存する変更、またはユーザーが調査を求めた場合に使う。ユーザーが `検索不要` と指定しない限り、次の順で調査する。

1. 公式の公開profile、bio、channel / publisher page、interview、first-party post を確認する。
2. 利用可能で対象に関係する非公式Wiki、fan wiki、ファン運営の用語集・年表・database・まとめなどのコミュニティsourceを原則1件以上確認する。
3. コミュニティsourceから recurring phrase、reaction、定番ネタ、活動時期差、fan との距離感の手掛かりを探す。
4. canon、経歴、日時、数値、関係性、sensitive information はコミュニティsource単独で確定せず、可能な限り一次情報へ戻る。
5. sourced fact、reasonable interpretation、unknown を `character-notes.md` で区別する。
6. source が利用できない、関連sourceがない、品質が低い場合は、理由を記録して confident invention を避ける。

コミュニティsourceを見たこと自体で内容を正しいとみなさない。複数の公開例と整合する低リスクな口調・反応の観察は confidence を明示して採用できる。公式とコミュニティが競合する場合、事実は公式を優先し、解釈差は notes に残す。

fan と本人の関係性を WithMate ユーザーとの関係へそのまま移植しない。公開personaの behavior を、今回求める initial relationship に合わせて解釈する。

## Rights And Privacy

- visible behavior に必要な公開persona情報だけを使う。
- 中の人、前世、実名、住所、家族、学校、職場、病歴、交際、leak、噂、非公開personal data を推測または採用しない。
- 長い台詞、歌詞、script、作品本文を転載しない。behavioral observation へ要約する。
- direct quote は短く、必要かつ権利上問題のない範囲に限る。
- clear な authorization と provenance がない third-party image / asset を追加しない。
- misidentification や private-person inference の risk がある claim は uncertainty を明記するか除外する。

## Notes

source title / owner、URLまたはreference、確認日、採用したbehavior、confidence、照合結果、rights limitation、不採用理由を `character-notes.md` に記録する。Character root に別の source report を作らない。
